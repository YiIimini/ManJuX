# ManJuX · 短视频创作工作台

> 从一段文字,到一部成片 —— 桌面级 AI 短视频生产线。
> 技术栈:Go(Wails v2 桌面框架)+ Vue 3 + Element Plus + Tailwind。

![ManJuX](build/appicon.png)

## 它能做什么

输入故事/创意文本 → **LLM 直出分镜与 H3 提示词** → 参考图资产 → **双引擎渲染**(本地 ComfyUI H3-Base / MiniMax H3 云端 API,音画一体直出)→ **机械质检**(黑屏防线)→ **合成成片**(字幕/响度/faststart)。

五阶段管线,每阶段可**独立运行、独立调参**(项目级参数快照),支持断点续跑、单镜重渲。

| 阶段 | 能力 |
|---|---|
| 剧本分镜 | LLM 直出角色卡/场景卡/分镜表 + 每镜完整 H3 提示词(Ref2VA 六段式/T2VA 三段式,对白原生配音);**镜数由内容决定、不设上限**(内容密的一章可正当需要 15-30 镜,不压并事件);思考型模型兼容(JSON mode 自动降级) |
| 资产定妆 | **Krea-2 自动生成**(角色 832×1248 半身/场景按画幅,~10s/张)/ 手动上传 / 跳过三级策略;已有资产自动复用;**角色自动补多视角转台图**(定妆照→H3 原地转身视频→抽帧拼接,渲染时作该角色的第二张参考) |
| 渲染出片 | **双引擎**:本地 ComfyUI(768p、Turbo LoRA、两阶段条件缓存·换图自动失效)/ 云端 MiniMax-H3 API(768P/2K);auto 本地优先自动切换;**镜头级引擎分派**;单镜失败不中断整批(断点续跑);**镜头级增强**:局部重绘(只重生成崩坏区域,其余画面逐帧保留)/ 音频驱动(配音驱动重渲,口型与节奏跟随音频) |
| 质检 | 时长/音轨/分辨率探测 + 抽帧亮度统计(黑屏防线);全流程中不阻断合成 |
| 合成成片 | 重编码拼接(硬切/闪黑/叠化 xfade)+ ASS 字幕(画幅自适应)+ loudnorm 响度(48kHz)+ faststart;**云端 2K 定稿**(regeneration,单镜/成片一键或自动) |

**桌面体验**:Wails 原生窗口(单实例)、渲染中关窗二次确认、实时 SSE 日志流、设置页一键测试连接(LLM/Comfy/MiniMax/VLM)。

**v0.4 扩展**:
- **跨项目资产库** —— 角色/场景一次定妆全局复用(Krea-2 生成与手动上传自动入库、同名秒级复用、复用计数、「资产库」页管理);系列作品天然形象一致;
- **VLM 智能审片** —— 抽帧送视觉大模型判分(默认智谱 glm-4.6v-flash 免费),输出问题清单与重渲建议,机械质检之上加内容级防线;
- **镜间连续接缝** —— MotionContext 22 帧钉入(项目级开关,仅本地引擎;上一镜无存档自动降级,云端/本地混合链可安全使用);
- **剪辑素材包导出** —— 按镜命名片段 + 成片 + 对齐 SRT + 导入说明一键打包(剪映友好,任意版本可导)。

**v0.30 能力升级**(详见 docs/):
- **整本小说批量产线** —— 小说库(目录导入/封面/阅读)→ 一键拆集(异步任务,提交即见占位卡,逐集实时刷新)→「书名·第NN集」子项目 → 批量产线逐集推进;按书分级管理 + 剧集弹窗单集操作;断点续跑三层保障(全流程跳过已完阶段/指纹记配置/批量跳过已成片集);
- **系列角色一致性** —— 后集分镜自动注入前集已确立的角色名与形象设定(书级 roster),配合资产库同名复用与角色锚定种子,跨集不换脸;
- **ComfyUI 引擎治理** —— 停止/退出全进程树杀(gopsutil 扫描,零残留)、空闲自动退出、代管 PID 持久化重启自动接管、版本管理与在线对比;
- **桌面体验** —— 运行日志悬浮窗(可拖动/调大小/一键停止管线)、批量管理全选/取消全选、图片上传拖放双通道(带缩略图预览)、六主题玻璃界面;
- **稳定性** —— WebView2 渲染期闪退根修(禁 webview GPU)、上传管线防截断(JSON+base64)、Tip 气泡最高层、合成 dissolve 转场修复、全子进程无黑窗。

**v0.34 能力升级**(详见 docs/):
- **拆集规则回归 1:1** —— **一章正好一集、集数=章数**,集名直接取该章标题原文(代码兜底强制覆盖 LLM 自起的文艺标题);镜数按内容给足、不设上限,不再靠「多拆集」换细度;
- **角色多视角转台图** —— 定妆照生成后自动用 H3 Ref2V 出「原地转身」短视频,抽 4 帧横向拼成转台图,渲染时自动作为该角色的第二张参考(仅在文件存在时追加,老项目参考图组成与渲染指纹不变);
- **镜头级增强** —— **局部重绘**(SAM3 跨帧跟踪目标 → 裁出 → H3 重绘 → 贴回原帧,只重生成手部/道具/人脸等崩坏区域,其余画面逐帧保留)与**音频驱动**(喂入定稿配音,H3 原生 `ref_audios` 条件驱动重渲,口型与节奏跟随音频);
- **资产库详情与重抽** —— 点击库卡片看该资产的**全部图片**(定妆照 + 转台图等关联图,存在 `_view_*` 多视角原图时一并收进来,每张带用途标签)、中文描述、英文提示词、来源与复用次数,可「抽卡」(同角色换一张)或删除;
  - **抽卡(换一张定妆照)**:同角色再摇一张(描述与提示词不动、只换随机种子);没有提示词的条目会先用 LLM 依描述推导一条,不再直接拒绝;
  - **描述与提示词可编辑 + AI 生成**:配了 VLM 就让它**看图**写中文描述与英文提示词(VLM 不可用时自动退回文本模型),也可手改后保存;
  - **补全多视角**(角色):库里只有一张正面照时一键生成 H3 原地转身多视角(约数分钟),渲染即自动作为该角色第二张参考;卡片上有「单视角」标记提示还缺哪个;
  - **角色多视角缺失自动补**:渲染前发现某个出场角色只有单张正面照时,自动补一次转身多视角并**写回资产库**(全局只付一次成本,后续项目复用即带角度图);项目内「资产定妆 ⚙」可关闭该行为;
- **渲染前节点预检** —— 渲染开始前校验本次用到的 H3 根节点是否齐备(缺则明确阻止并给中文提示,不再跑到一半炸 `node_errors`),并检测已知冲突插件(只告警不阻断);
- **风格与身份分离(一致性铁律)** —— 风格块只描述渲染表面(材质/光泽/媒介),**绝不含形状类词汇**(曾因 `large glossy stylized eyes` 把所有角色画成圆脸大眼,与角色卡"细长单眼皮"对打,导致定妆照/多位图/视频三张脸);新增"忠实度硬约束":脸部必须与角色卡逐项一致,不得美化/放大眼睛/柔化下颌/变年轻;同剧对比名单只作差异化参考、明令不许画出来;
- **身份一致性治理** —— 渲染提示词改为**以定妆照为准**(旧版写「外貌描述优先级最高」,等于让模型忘掉参考图按文字重画:同剧角色脸趋同、文字里的痣/红鼻头出现在成片而定妆照没有);同一角色换称呼(机关人/阿枢/一三七四一号)不再重复生成定妆照(库内按名字归一化 + 别名 + 描述相似度判同一人并登记别名);多视角转台图不再把成年角色 Q 版化、不再凭空长腮红红鼻头(身份锚点剥离面部词汇、四帧锁同一景别、体型以参考图为准);
- **台词语言锁定** —— H3 靠 `<d>[Chinese]台词</d>` 的语言标记决定说什么语言,LLM 漏标记就会出现听不懂的"鸟语";现由代码在存盘前/渲染前/2K/局部重绘/音频驱动五处统一补齐标记并追加"MANDARIN ONLY"强制中文;
- **渲染资源治理与 Sage 加速** —— 引擎代管启动带上内存治理参数(`--cache-none` 不缓存节点产物、`--disable-smart-memory` 用不到就卸载、`--vram-headroom` 连别的程序占了也算、给系统留白);**Sage Attention 官方提速约一倍**(实测同镜 91.6 → 44.8 秒/步、单镜 819 → 432 秒、内存峰值 96% → 73%),需装匹配本机 torch/cu130 的 sageattention 轮子,装好后自动启用、设置页可一键关;管线收尾与一次性操作(抽卡/补全多视角/局部重绘…)做完即释放显存并在日志如实报出降幅(队列有活/管线在跑时自动不抢);
- **参考图去冗余** —— 转台图左起第一格就是定妆照,渲染时只喂这一张(每个角色参考图 2→1 张),信息不减、显存与内存占用更低;项目「资产定妆 ⚙」可关(需复现旧渲染指纹时);渲染日志会写明「参考图 N 张:角色 X + 其中拼合转身图 Y + 场景 1」;
- **Sage 加速自愈** —— 管理页显示 Sage 状态(装了没/哪个版本/本机 torch 与 CUDA/会不会启用)并提供一键安装更新:按本机 torch+CUDA 自动匹配官方推荐发布源的轮子(pip 只装这一个包、不动 torch),升级 ComfyUI/torch 后不再"莫名变慢"而查不出原因;
- **管线生产串行化与超时口径** —— **同一时刻只跑一条管线**(多集并发共用一张显卡只会互相伤害:定妆照排在长视频任务后面排队被杀、单镜从 3-5 分钟涨到 20+ 分钟);**排队不再吃掉执行预算**(超时只计"真正在执行"的时间,日志如实报「排队中 · 已等 X 分」,定妆照不会再因为排队被误判"渲染超时");批量产线按**产物进展**判断某集是否卡住(连续 60 分钟无任何新产物才暂停),不再拿固定时长当"这集跑完了"——那会让上一集还在渲染时下一集就开跑;
- **2× 放大后处理** —— LTX 隐空间 2×(含 8n+1 时间轴补齐、裁回原帧防时长漂移)与 ESRGAN 帧级 2× 两条链路,均保留源音轨;模型已就位(`ltx-2-spatial-upscaler-x2-1.0` / `4x-UltraSharp`,以及隐空间链路必需的 LTX 视频 VAE `LTX2_video_vae_bf16`)。**已端到端接通并经真机实测**:故事板镜头卡「2× 放大」下拉(帧级 / 隐空间),端点 `POST /api/projects/{id}/shot/{shotID}/upscale`,默认帧级;帧级最忠实(硬边细字保得住)但慢(768P 约 3.8 秒/帧),隐空间更快且实拍质感更好(同素材 48 帧 ≈ 18 秒)但会抹软片内细字;**提交前先体检权重**,缺文件直接点名目标目录,不用等 ComfyUI 跑到那个节点才知道;
- **ComfyUI v0.35.1** —— 含 `Fix MiniMax H3 denoise masks`(局部重绘依赖的底层修复);新增 MaskVidExperiments、comfyui-vrgamedevgirl 插件;
- **工程改造** —— 三个千行文件拆分(`pipeline.go`/`server.go`/`novels.go`)、引擎接口收口(`FreeVRAM`/`ClearQueue`/`Interrupt`/`GenerateImage` 提升进 `engine.Engine`)、前端请求全部收口到 api 层、测试函数 12→64。

**v0.35 观感与音质治理**(详见 docs/CHANGELOG.md):
- **角色动漫化 + 去油腻 + 不影射真人** —— 定妆照端(Krea-2)与视频端(H3)**两头同时**压画风:手绘线稿 + 赛璐璐平涂 + 哑光粉质肤色、柔和低对比散射光,并显式排除油光/汗湿反光/塑料蜡质/真人照片脸/影射真实人物与演员。定妆照端只能写正面描述(蒸馏模型对否定词免疫却会照着名词画),视频端才能写排除句 —— 两块的用词边界有测试钉住。默认风格改为**国漫二维**,新增「角色动漫化」开关(默认开;要真人剧可关);
- **多视角转台图校验后交付** —— 转身视频抽帧后**逐帧核对是不是定妆照里那个人**,不一致换种子重出,仍不一致就**拒绝使用**(删掉角度帧、退回单张正面照渲染),不再让一张错的参考图把成片人脸往错的方向拉;没配视觉模型时跳过校验并如实写日志;
- **配音不切词** —— 分镜侧按 4.5 字/秒核算台词时长,**装不下就自动抬镜头时长**(提示词同步写死这条算术,超上限则建议拆镜);合成侧把叠化转场必须让出的那段音频**切在静音上**(RMS 包络求解切点),不再每镜头尾各砍 0.25 秒、切掉台词尾巴;质检新增「实测人声时长 vs 应有台词时长」告警;
- **音频去杂音** —— 新增音频净化链(高通 + 频谱降噪,默认开)、响度改为**两遍法**(先测量再线性增益,不再逐帧抽气)、硬切路径的音频改用 concat 滤镜重建(消除 AAC priming 造成的接缝"咔"声)、中间轨走 flac/mkv 无损;分镜提示词新增音景纪律(底噪只写 1-2 句,不堆叠声源);
- **工程收口** —— 新增 `internal/audio`(包络/静音分析/切点求解,纯函数可测)与 `internal/pipeline/artstyle.go`(画风块单一来源);角色定妆照提示词收口到 `characterImagePrompt()` 唯一装配点;新增端到端合成测试(真 ffmpeg 跑通叠化+字幕+净化+两遍响度,并断言接缝落在静音)。

## 快速开始

1. **双击 `ManJuX.exe`** —— 弹出桌面工作台窗口(单实例,重复启动自动唤起已有窗口)。
2. **设置**(右上角):填写 LLM(OpenAI 兼容,推荐 DeepSeek)与 MiniMax API Key;本地 ComfyUI 路径默认已适配本仓库 `comfyui/` 目录。
3. **新建项目** → 剧本页粘贴故事文本 → 「一键全流程」或逐阶段运行。
4. 渲染与合成进度在底部 **RUNTIME LOG** 实时滚动;分镜故事板逐镜点亮;成片页预览/导出。

## 构建与发布

```powershell
# 提交前自检:六道闸门一次跑完(gofmt / go vet / go build / go test / 前端构建 / 第三方补丁在位)
# 改完代码先跑这条 —— 尤其改了 frontend/src 时,不重建 webdist 就等于界面改动没生效
powershell -ExecutionPolicy Bypass -File scripts\check.ps1

# 日常构建(前端+桌面 exe)
powershell -ExecutionPolicy Bypass -File scripts\build.ps1

# 发布(自动构建 → commit → tag → 推送 GitHub 私有仓)
powershell -ExecutionPolicy Bypass -File scripts\release.ps1 -Note "说明"
```

依赖:Go 1.25+、Wails CLI(`go install github.com/wailsapp/wails/v2/cmd/wails@latest`)、Node+pnpm、ffmpeg(PATH)。

## 环境要求

- 本地渲染:ComfyUI(本仓库 `comfyui/` 即完整环境,含 MiniMax-H3 int8 模型);应用可代管启动。
- 云端渲染:MiniMax 开放平台 API Key([platform.minimaxi.com](https://platform.minimaxi.com))。
- 剧本生成:任意 OpenAI 兼容 LLM(DeepSeek/GLM/Qwen/Kimi/本地 vLLM 均可)。
