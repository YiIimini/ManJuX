# 视频制作与封面重做：两条入口的功能逻辑（2026-10-10）

用户：「小说视频制作和封面重做也需要重新实现功能逻辑」。

先说结论：这两条入口各有一个**真机撞得到**的洞，而且病根同型 —— **该说的没说、该能用的不能用**：

| 入口 | 改前 | 改后 |
| --- | --- | --- |
| 封面重做 | 这本书**没有留档正向词**（`封面/pos-qwen21.txt`）⇒ `GET /api/novels/cover-config` 回 **400** ⇒ **弹窗根本打不开** | 一律 200：没有留档词就给一份**按书名与本书风格推的默认词**＋一句 hint，弹窗照开、用户直接改 |
| 视频制作 | 书**没有封面图**时 `applyCover` 里 `if cover == "" { return }` **静默跳过** ⇒ 一集集建出来全都没有封面，用户不知道原因 | 建集之前**如实播报一次**（与「脚本创作·包导入」那条入口**共用同一句、同一个级别**） |

一句话：**"既没有封面、又没有留档词"恰恰是封面重做最该顶用的场合，却成了唯一走不通的场合**；
而视频制作在同一个情形下**一句话都不说**。同一个平台上「脚本创作·包导入」那条入口本来就是如实报的
（`applyNovelCover`），两条入口口径不一，用户看到的就是"两个不同的问题"。

---

## 一、封面重做：从"打不开"到"有个能改的起点"

现场（`novels_cover_redo.go` 改前）：

```go
raw, err := os.ReadFile(coverPromptPath(bookDir))
if err != nil || strings.TrimSpace(string(raw)) == "" {
    writeErr(w, 400, fmt.Errorf(
        "这本书没有封面正向词(%s):先让技能端生成一次封面(gen_cover.py),或在这儿直接写一份再生成", …))
    return
}
```

这句 400 自相矛盾：它说"或在这儿直接写一份再生成"，可**"这儿"就是那个打不开的弹窗** ——
前端 `openCoverDialog` 的 `covOpen.value = true` 在 `await` 之后，config 一失败就只弹一句红字提示。
另外，候选对比视图（`CoverCompare.vue`）里专门写着「**这本书还没有封面**」：
也就是说"没有现封面"这件事平台早就考虑过，唯独"没有留档词"把整条路堵死了。

改后：

* `handleNovelCoverConfig` **一律 200**，新增三个字段：
  * `has_prompt`（有没有留档文件）；
  * `applicable`（书必须是**目录**；散文件小说没有 `封面/` 目录，候选图无处可放 ⇒ false）；
  * `hint`（一句话说清当前状态与下一步）。
* 没有留档词时 `prompt` 由 **`coverSeedPrompt(bookDir, bookName)`** 给：组成**全部来自这本书
  自己声明过的东西**（唯一出处 `scanNovelStyle`：立项.json 的 art_style/渲染风格串/画风、
  或 设定集/视觉风格卡-*.md 的风格串）＋ 书名 ＋ 一条固定的竖版封面口径（留标题位、
  **不出现任何文字/水印** —— 图像模型画不出可用的中文字，让它"画字"只会得到一排乱码）。
  **不调模型、不猜剧情**，它只是"有个能改的起点"。
* `handleNovelCoverRedo` 对散文件书：400 且**说清是哪一类书不行**（原来只报「书目录不存在」，
  而它明明就在那儿）。
* 前端：菜单项对散文件书**置灰**；弹窗顶部显示 `hint`；正向词标签在无留档词时写「平台推的默认词,可直接改」。

真机探针（`TestZZProbeCoverSeedLive`，`MANJUX_LIVE_PROBE=1`，读盘上那本书）：

```
本书风格字段：Found=false Field="" Card=""       ← 这本书什么都没声明
封面默认词（86 字）：《离婚后，千亿前夫跪求复合》的小说封面主视觉（竖版 3:4）。
                    构图：单一主视觉居中偏上，下三分之一留出标题位置；干净背景、电影级打光；
                    画面里不出现任何文字、字幕、水印与签名
```

## 二、视频制作：缺封面图必须说，而且只说一次、说同一句

`novels_produce.go` 的 `applyCover` 原来是这样开头的：

```go
if cover == "" {
    return          // ← 静默：一集集建出来全没封面，用户看不到任何提示
}
```

这正是 2026-09-29 审计同型缺陷的**另一半**：那次修的是"封面**写失败**要报"（`os.WriteFile` 的
返回值被丢掉），这次修的是"**根本没有来源**也要报"。

改法：

* 新增**唯一出处** `novel_cover.go` 的 `missingCoverMsg(book)` + `(s *Server) noteMissingNovelCover(book)`；
  「脚本创作·包导入」那条入口（`applyNovelCover`）也改用它 —— 两条路**一句话、一个级别（warn）**，
  句子把两条可行路径都说出来（① 放一张 `<书目录>/封面/封面.png`；② 用「封面重做」出图 →「用这张」，
  它会一并刷新这本书的集项目封面）。
* 播报点放在 **goroutine 之前**：无论拆集成败这句话都会出现，且**只出现一次**
  （`applyCover` 会被每批回调多次，报在那儿会刷屏）。

## 三、顺带把"视频制作吃 .docx"钉到端到端

上一轮把小说库的格式判据收口了（`.docx`/`.epub`），但那只是"函数认识"。
这一轮补上**行为级**的端到端门 `TestProduceDocxBookBuildsEpisodesAndReportsMissingCover`：
真机同形的书（书名带全角逗号、8 个中文数字章号的 `.docx` 平铺、**没有「正文」目录**、**没有封面图**）
点「视频制作」⇒ 8 集建出来、**每集的 `source.txt` 里【本集原文】就是那一章**（章头 + 该章独有的
特征串，且不许混进别章的内容）、并且有一句「没有封面图」的 warn。整条链**不调 LLM**
（一章一档快路径），所以单元测试里跑得起来（实测 0.06 秒）。

## 六、顺带咬出一条真数据竞争（八门第 5 道）

这一轮的端到端门（`TestProduceDocxBookBuildsEpisodesAndReportsMissingCover`）一进 `-race` 就红了：

```
WARNING: DATA RACE
Write at ... by goroutine 34:
  handleNovelProduce.func2()   novels_produce.go:214   ← 异步 goroutine 里 `name = safeSeries(name)`
Previous read at ... by goroutine 9:
  handleNovelProduce()         novels_produce.go:273   ← handler 随后拼响应文案 `"《" + name + "》已提交…"`
```

这不是测试的毛病：`handleNovelProduce` 起了 goroutine 之后**继续读同一个局部变量** `name`，
而那段 goroutine 的第一件事就是**写它** ⇒ 用户点一次「视频制作」就踩一次 undefined behavior
（表现是"接口回的标题偶发是规整前 / 规整后的"）。修法**局部遮蔽**：`name := safeSeries(name)`，
goroutine 里后面所有用到它的地方（拆集入参、失败文案、`jobSet`）都用这一份，
handler 自己那份原样不动（响应里给用户看的本来就该是原名）。

**门** `TestProduceGoroutineDoesNotWriteCapturedName`（机械回归守卫，只看代码行；反向针 N8 全红）——
真检测器仍是**八门第 5 道 `go test -race`**：正是它咬出来的，这条守卫只是不必再等它恰好抽到那个调度。

## 七、边界（如实说）

* **默认词不调模型**：它只是"能改的起点"，不是"平台替你写好的封面词"。要更好的词，用户自己改，
  或让技能端出一版（勾「把新正向词存回封面留档」就写进 `封面/pos-qwen21.txt`）。
* **散文件小说（小说库根下直接一个 `.md`/`.docx`）做不了封面重做** —— 没有书目录就没有 `封面/`，
  候选图无处可放。菜单置灰 + 后端 400 都只说一件事：请到集项目里换封面。这是**永久边界**。
* **没有封面图时不会自动生成一张**：封面是创作动作，得有人给词（见上）。视频制作只做到
  "如实告诉你 + 告诉你两条路"；集项目封面仍按 `projectCover` 的既有兜底顺序显示（首个角色定妆照）。
* 这一轮**没跑真机出图**（没有 GPU 侧 ComfyUI 在线验证）；门只钉"能不能开、给的是不是那句话、
  落盘的是不是那一章"这些确定性的事。
