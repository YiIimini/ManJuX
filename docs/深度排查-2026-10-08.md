## 3. 反向验证：13 处「改坏 → 守卫变红 → 改回」

脚本在 scratch（`reverse_verify_deep_2026-10-08.ps1` / `deep2` / `deep3`），做法是**精确替换一处源码 → 跑对应守卫 → 还原**。

|---|---|---|
| ① | 关掉频域八度纠正 | 变红 ✔（110:1+220:4 读出 220.9） |
| ② | **整段回退 `audio/pitch.go` 到 HEAD**（旧实现） | 变红 ✔：`220.9 / 260.8 / 220.9 / 220.9 Hz（差 101%）` 与 `400 Hz → 200.3 Hz` 全部复现 |
| ③ | 去掉重叠带"不判"分支 | 变红 ✔ |
| ④ | 节标记退回纯 `strings.Index` | 变红 ✔ |
| ⑤ | 空壳也算"有剧本" | 变红 ✔ |
| ⑥ | 回填不清"照抄的抬头" | 变红 ✔ |
| ⑦ | 指纹去掉内容哈希 | 变红 ✔ |
| ⑧ | 清理时当前文件为空就不再留归档 | 变红 ✔ |

| ⑪ | 资产指纹键退回裸 id | 变红 ✔ |

**这一步抓出了两个"摆设守卫"（过程如实记账）**：

- ② 第一次用的针是"把搜索下界挪一个 lag"，结果**仍绿** —— 抛物线插值把偏差补回来了。
  改用**整段回退到旧实现**才红；同时把 400 Hz 的容差从 6% 收紧到 **2%**（实测误差 0.1%）。
- ④ 第一次的针改的是 `EpisodeBrief` 的**起始**查找，而夹具咬的是 `EpisodeSectionEnd` 的**结束**边界
  ⇒ 仍绿。针换到承重点上才红。

> 结论（写进纪律）：**反向验证的针必须落在承重点上**；"改坏了还是绿的"要当成一次发现，
> 而不是当成"这条不重要"。

### 8.3 修法（三处，都接在同一条链上）

1. **`internal/director/repair.go` 新增 `emptyShotFix(plan, sh)`**（根因）：把这一镜**已有的材料全写进指令**——
   时长、场次（id(名字)）、人物（名字 + 这一镜的走位，id/名字两种键都试）、景别、机位、动作（空就**明说**
   "the beat is not written in the storyboard … do NOT invent new action"，不许让模型自己编）、以及**逐句台词原文**
   （说话人 + 是否画外 + "EXACTLY N line(s), each spoken once, word for word" + "NO other `<d>` line anywhere"）。
   这既是给模型的材料，也是给采纳闸门的**可机检靶子**（`adoptRepaired` 就按句数数）。
2. **新增 `internal/project/empty_body.go`：`FillEmptyShotBodies` / `assembleMinimalBody`**（装配点兜底）：
   正文为空、但**材料够**的镜，按方案自己的材料拼一版**最小合规正文**——六段顺序、风格句取**同集兄弟镜**
