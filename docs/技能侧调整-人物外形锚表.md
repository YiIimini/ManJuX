# 技能侧调整 · 人物外形锚表

> **一句话**：小说正文里**几乎不写外貌**，而平台的 LLM 直出必须从正文里提炼人物卡 ——
> 于是**整套外形是 LLM 现编的**。要让它稳定、可复现、合你的意，就得有一张**显式的外形锚表**。

---

## 一、实证：外形是谁写的

平台现在的渲染输入 = **小说正文**（`internal/server/novels_produce.go`，读章节、跳过 `设定集/`）。

实测《求你们骂我》第 001 章（2247 字）里的人物描写：

| 人物 | 正文里能拿到的外形信息 |
|---|---|
| 沈砚（主角） | **零** —— 只有"沈砚睁开眼，正躺在一摊泔水里"、"后脑勺磕出一个包" |
| 苏晚 | `十八岁，鹅黄裙衫，手里捏着扇子`（年龄 + 服装，无长相） |
| 周廷 | `青缎长衫，腰挂玉`（只有服装） |
| 卖菜婆 / 壮汉 | 无 |

而平台 LLM 写出的角色卡是：

> 二十二岁上下的年轻男子，身形清瘦但肩背挺直，**瘦长脸、下颌线清晰，眉骨高，深棕色丹凤眼眼尾微上挑，鼻梁挺直，薄唇，皮肤冷白哑光；左眉尾有一道短疤**；黑发，用一根素麻绳在脑后扎成低马尾，发长及肩胛，额前全部向后梳净…

**这些字正文里一个都没有。** 整套外形是 LLM 补的。

## 二、后果（为什么这是真问题）

1. **形象不可复现**：同一个角色，换一次直出（或换个项目重跑）可能补成另一张脸 —— 而"脸"是漫剧最贵的资产，观众认的就是它；
2. **你的意图没有落点**：你心里的沈砚长什么样，**没有任何地方写着**，也没人能改；
3. **跨集/跨季漂移**：一季做完再做第二季，两张脸对不上；
4. 若将来做有原著的作品，补出来的外形会与原著冲突。

## 三、要做的事：建一张「人物外形锚表」

**位置**：`<书名>/设定集/人物外形锚表.md`
（与你们既有的 `设定集/数字锚表.md` **同构** —— 数字锚表防数字漂移，这张防外形漂移，是它的镜像）

**每人一条，字段固定**：

| 字段 | 要求 | 例（沈砚） |
|---|---|---|
| 姓名 | 与正文一致 | 沈砚 |
| 年龄 | 数字或区间 | 22 岁上下 |
| 身形 | 高矮胖瘦 + 体态 | 清瘦，肩背挺直 |
| 脸型 | **形状词** | 瘦长脸，下颌线清晰 |
| 眉眼 | 形状与神态 | 眉骨高，深棕色丹凤眼、眼尾微上挑 |
| 鼻唇 | 形状 | 鼻梁挺直，薄唇 |
| 肤色/肤质 | 色 + 质感 | 冷白，哑光 |
| **独特记号** | **至少一个** | 左眉尾一道短疤 |
| **发型三要素** | **束法 / 长度 / 额前状态** | 素麻绳低马尾；及肩胛；额前全部向后梳净、无碎发垂面 |
| 首套服装 | 材质 + 颜色 + 样式 | 灰白色粗布短打，袖口磨破，旧汗巾搭肩，草鞋 |
| 气质（可选） | 一句话，**不许替代外形** | 冷静，眼神很亮 |

### 硬要求（这几条踩过坑）

- **眉眼不许用尺寸词**（`large` / `big` / 大眼睛 / 水汪汪）—— 与你们自己的比例锚点「两眼间距＝一个眼宽」「不许放大眼睛」**直接冲突**，同一段提示词里两个相反指令，模型只会折中。用**形状与神态**词：丹凤眼 / 杏眼 / 细长单眼皮 / 眼尾微上挑 / 目光沉着。
- **不许用抽象词代替外形**（绝美 / 出尘 / 天人之姿 / 气质无双）—— LLM 提炼不出可画信息，只会再编一个。
- **发型三要素必须齐全**（束法 + 长度 + **额前状态**）。缺"额前状态"是当年"头发越来越长、额前垂一大绺"的根源，平台侧为此专门加了发型纪律；锚表里给全，比事后补救便宜。
- **每个"有脸的"角色都要有**。纯一次性背景角色可以只给最少四项（年龄 / 身形 / 脸型 / 服装）。
- **正文与锚表不得矛盾**；矛盾时**以锚表为准**（平台会把它当硬约束喂给 LLM）。

## 四、正文里怎么写（与锚表的关系）

- 正文**不需要**大段外貌描写 —— 那是文学层面的事，锚表已经承担了"可画信息"的职责；
- 但**首次出场**给一个**最小可画锚点**有帮助（哪怕一句：`二十出头，瘦长脸，左眉尾一道旧疤`），让读者与 LLM 都有落点；
- 后续章节**不要改外形**：`今天她换了发型` 要写成"换了发髻"，**不要改发长**；服装可以换，脸不能换。

## 五、平台侧配合（平台的事，技能侧知悉即可）

- **现状**：平台读小说时**跳过 `设定集/`**（`internal/server/novels_produce.go:52` 的排除列表里有"设定"）→ 锚表写了也读不到。
- **平台侧要改**：把 `<书名>/设定集/人物外形锚表.md` 纳入直出输入，作为「人物外形·硬约束」交给 LLM，并要求逐项照抄。
- 分工：**技能侧写表 → 平台侧保证它被读到、被执行**。

## 六、验收（建议机检）

- 每本书 `设定集/人物外形锚表.md` 存在，且覆盖正文里所有有名字的角色；
- 每人字段齐全（≥9 项，发型行含"束法/长度/额前"三要素）；
- 眉眼行**不含** `large` / `big` / `绝美` / `出尘` / `天人之姿`；
- 锚表与正文首次出场描述不矛盾。
