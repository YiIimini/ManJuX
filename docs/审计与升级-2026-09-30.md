## 五、本轮**跑不了**的一门（环境事实，不是"验过了"）

`scripts/check.ps1` 的**第 6 门（vite build）在本机跑不了**：这台机器上**没有 Node/pnpm** ——
`where node` 无、`D:\Ai`（含 `D:\Ai\DSH Desktop`）、`C:\Program Files*`、用户 AppData 全盘搜过，
`node.exe` 一个都没有（`D:\Ai\DSH Desktop\resources\app\node_modules\pnpm` 只是 pnpm 包，
没有 node 可执行体）。历史会话里那一门能过，说明**当时有 node**（或换了环境）。

后果与处置：
* 前端源码改动（§一 的 8、9）**已改完但未编译**——它们要等一次 `pnpm run build` 才会进 webdist；
* 本轮重编的 exe 里嵌的是**旧的 webdist**（后端修复全部生效，界面修复待前端构建）；
* **谁有 node 谁跑一次** `powershell -File scripts\build.ps1`（它会先建前端再建桌面），
  或 `powershell -File scripts\check.ps1` 补上第 6 门。

其余各门本轮**手动等价跑过**（结果见 §六）。
