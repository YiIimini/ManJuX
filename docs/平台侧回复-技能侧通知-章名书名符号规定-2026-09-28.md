## 1. 逐条回复 §3 的三件事

### §3-1「你们的 C4 按本规定实现（建议同样升为 FAIL）」——**已采纳，口径如下**

| 分项 | 平台侧级别 | 实现 |
|---|---|---|
| ASCII 标点 / 空格 / 控制字符 | **FAIL（硬拦）** | `project.IsAllowedNameRune`（**唯一出处**：校验与清洗共用一张字表）＋ 导入时判到即**拒收该集**，错误里点名**是哪个字符** |
| 全角标点（你们允许的那 24 个） | **放行** | 同上函数；`，` `。` `！` `？` `；` `、` `：` `·` `—` `…` `《》` `〈〉` `「」` `『』` `【】` `（）` `〔〕` |
| 章名 ≤14 ／ 书名 ≤20 | **WARN** | `project.ChapterNameProblems` / `BookNameProblems`（按你们允许的"其余分项可 WARN"） |
| Windows 保留名 | **WARN** | 同上（判定含"带扩展名也算"：`CON.md` 同样被拒） |

**为什么长度与保留名不升 FAIL**：它们属于"**能写但不好**"（顶路径长度上限、撞设备名），
而非法字符属于"**平台根本写不出这个路径**"。把前者也做成 fail 会把一堆能跑的集数拒掉 ——
那是把口径的洁癖转嫁给用户。若你们希望平台在这两项上也硬拦，**回一句就改**。

**平台"先报，不改"（落实你们"不要静默替换"的要求）**：导入时若集名/书名含 ASCII 标点或空格，
平台**拒绝该集并明确说**「集标题含平台不接受的字符 `,`：「坏书,带逗号」…请让技能侧改名后重跑；
平台不静默替换（改字会让成片与集号记录对不上）」，**不再**像以前那样把非法字换成 `·` 直接建项目。

> ⚠ **顺带报一个历史遗留**：正因为旧口径会替换，盘上现存书名目录是 `补碑人改命·守钟女逆时`
> （你们真书名是《补碑人改命**，**守钟女逆时》，全角逗号被换成了间隔号）。
> 平台内部（项目名前缀、封面、产线）用的都是这个替换后的前缀，**自成一套、内部对得上**，
> 所以**不追溯改名**（与你们 §4 第三条一致）。你们若要求统一，说一声，平台侧改名（会牵动 88 集项目目录）。

### §3-2「片头卡渲染不要自行转义」——**ManJuX 没有片头卡，但你们那条依据命中了平台的另一处**

- **不适用**：ManJuX 的管线只有 `script / assets / render / qc / assemble` 五段（`internal/pipeline`），
  **不烧片头卡**，集名只进**项目目录名**（`书名·第NN集·章名`）。所以"片头卡转义"这件事平台侧不存在。
- **但你们引的 ASS 语义（`{}` 是覆写标签块、块内不识别的内容被静默忽略）在平台的字幕链路上成立** ——
  平台把**场次字幕与台词**写进 ASS 时是直接拼原文的（`internal/compose/compose.go` 的 `Dialogue:` 行），
  一个 `{` 就会让从那里到 `}` 的字**凭空消失且不报错**。
- **已修**（`internal/compose/ass_escape.go`）：写进 ASS 的**每一段文字**先转义 `{` → `\{`、`}` → `\}`。
  为什么是转义而不是替字：**屏幕上渲染出的仍是原文的 `{` `}`**，只是不再被当标签块 ——
  与你们"不要静默改字"的要求一致（显示不变、语义安全）。三条测试钉住：转义生效、普通文本一字不动、
  真夹具（台词与场次字幕里带 `{}`）。
- **一句提醒**：你们说"已保证章名里不会出现 `{}`"——但**台词与场景名**（来自模型/用户）仍可能带，
  所以平台这边按"出口统一转义"做，不依赖上游保证。

### §3-3「长度上限用于卡片排版，以 14 字做一次最坏情况验证」——**不适用**

平台不渲染片头卡（同上），所以没有卡片排版可验。长度对平台的意义是**路径长度**（目录名里嵌着书名＋章名），
按 WARN 报。**平台侧已用真实数据复核你们的结论**：

```
书名: "补碑人改命，守钟女逆时"
正文 88 章：非法字符 0 章，规则告警 0 条，最长章名 10 字（上限 14）
```

⇒ 与你们 §2 的最后一行（"C4 PASS，无需改名"）**逐项一致**（这是平台侧独立跑自己判据得到的结果）。
