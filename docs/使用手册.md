# ManJuX 使用手册

## 首次启动

1. 双击 `ManJuX.exe`(或 `build\bin\ManJuX.exe`)→ 桌面工作台窗口自动打开。
   - 重复双击不会开第二个窗口(单实例,自动唤起已有窗口)。
   - 关闭窗口即退出程序;**渲染中的项目请先停止再关闭**。
2. 首次使用请进「设置」完成三件事:

| 配置项 | 说明 |
|---|---|
| 文本大模型(LLM) | OpenAI 兼容接口。推荐 DeepSeek:`https://api.deepseek.com/v1` + `deepseek-flash`(官方推荐,默认值;旧 v4-flash/v4-pro/chat/reasoner 已退役)+ 你的 Key |
| MiniMax H3 API | 云端渲染必填。国内 `https://api.minimax.cn`,Key 在 platform.minimaxi.com 创建 |
| 本地 ComfyUI | 默认已指向 `D:\Ai\ManJuX\comfyui`,保持默认;勾选「自动代管启动」后无需手动开 ComfyUI |

顶部状态灯:LLM / ComfyUI / H3 API / ffmpeg,绿色=就绪。橙/红=待配置或未启动。

## 创作流程(从文字到成片)

### ① 新建项目
首页「新建项目」→ 输入项目名(中文/字母/数字/_-)。

### ② 剧本分镜(script)
「剧本」页粘贴故事/创意文本 → 点管线卡片「剧本分镜 ▶」(或顶部「一键全流程」)。
LLM 直出方案后自动生成:
- 角色卡(外貌固定描述 + 定妆照提示词)
- 场景卡
- 分镜表:每镜含景别/运镜/动作/台词/旁白/时长/**完整 H3 提示词**(点镜头卡上的 📄 图标查看)

调优入口(管线卡片 ⚙):镜头数(0 = 由内容决定,最多 120)、目标时长、**渲染视频风格**(国漫二维 / 都市仙侠 / 3D 皮克斯 / 水墨 / 赛博朋克 …可多选)、**角色动漫化**开关、风格附加要求(如"国风仙侠""赛博朋克霓虹")。

**角色动漫化(默认开)**:角色一律按动画化人物渲染 —— 手绘线稿 + 赛璐璐平涂 + **哑光肤色**,并显式排除油光、汗湿反光、塑料蜡质感与"真人照片脸 / 影射真实人物与演员"。它同时解决三件事:去掉"人物油腻"的观感、避免真人脸、避免肖像侵权。开关**两头都生效**(定妆照与视频提示词各压一次),关掉才会走写实路线。

- 风格里写了「真人实拍质感」而本开关开着时,会**按动漫化渲染并在日志告警** —— 要拍真人剧请关掉本开关,并把风格设成「真人实拍质感」;
- 老项目默认也是开(参数快照里没有这个键即视为开)—— 想保持原样请手动关掉。

**台词时长预算**:分镜阶段会按普通话约 4.5 字/秒逐镜核算台词 —— 装不下就**自动加长该镜时长**(最多 10 秒),超过上限则告警建议拆成两镜。这一步是"配音不完整"的分镜侧根治:20 字台词塞进 4 秒镜头,模型只能说一半就被截断。

**镜头数默认 0(内容驱动)**:由 LLM 看原文节拍自行决定拍多少镜 —— 内容密的一章可以正当地需要 15-30 镜,宁可多给几个小镜头,也不要把几件事压进一镜(压并会让观众前后不知所云)。填具体数字则按指定值生成,上限 120 只是防手改 JSON 的安全网。

### ③ 资产定妆(assets)
三种策略(「资产定妆 ⚙」可选):
- **Krea-2 自动生成(推荐)**:每个角色/场景自动出图(角色竖幅 832×1248,取景按**实体类型**定,场景按项目画幅),约 10 秒/张;
- **手动上传**:「资产」页为每个角色上传参考图(人:半身正脸;器物:整件;妖兽:全身)、场景上传全景参考图(锁脸最稳);
- **跳过**:全部镜头纯文生 t2va。

**角色按实体类型渲染(2026-09-24 起,六类各有各的方法)**:每张角色卡带一个**类型** ——
**人 / 物 / 灵宠 / 妖兽 / 无实体 / Q版**。类型不同,三件事都不同:

| 类型 | 定妆照取景 | 多视角方式 | 身份锁(渲染时) |
|---|---|---|---|
| 人 | 半身正面 | 原地转身 | 脸型/五官/发型/肤色照抄定妆照 |
| 物(器物/机关/傀儡/雕像) | **整件居中、三视图** | **转台自转** | 轮廓/部件数/材质/做旧照抄;**禁止拟人化** |
| 灵宠 | 全身兽形 | 转身环视 | 物种/毛色/花纹/体型;**不得拟人化** |
| 妖兽 | 全身兽形、显体量 | 转身环视 | 物种/角牙爪翼尾/体量;**不许缩水** |
| 无实体(鬼魂/灵体/投影) | 整团形体、暗底 | 原地旋动 | 形体/发光/透明度;**不得实体化、不得落地成影** |
| Q版 | 大头小身全身 | Q版转身 | 头身比/身份记号,不得拉回真人比例 |

- 类型由分镜阶段自动判定(按"这东西物理上是什么",不是按它有没有台词/名字);**存量项目
  由程序按名称与描述推断**,判错了就在「资产定妆 · 详情」的卡片下拉里直接改 —— 改类型会
  自动作废按旧类型出的角度图,并提示你点 ✨「重新生成」重出定妆照;
- 起因是一只机关铜雀(阿凿)被当成人物渲染成了半身人像(那张错图还会被当成第一参考喂回整集),
  所以**器物/无实体的"不得拟人化/不得实体化"是不受画风开关影响的硬条款**。

角色定妆照生成后会自动补一张**多视角图**(H3 转身/转台短视频 → 抽帧 → 横向拼接,约数分钟,日志里能看到进度):转身、走位、多人同框时身份更稳,渲染时自动作为该角色的第二张参考。这是增强项,任一步失败只告警、不影响定妆照与后续渲染;**旧项目不受影响** —— 多视角图只在文件存在时才被追加为参考,没有它的项目参考图组成与渲染指纹都不变。

**多视角要过校验才交付**(2026-09-24 起):转身视频是生成的,模型有创作自由,可以把主体转着转着画成另一个样子。抽帧后会**逐帧核对该类型的关键特征**(人看脸、器物看结构与材质、灵体看形体与透明度)是否与定妆照一致,不一致就换随机种子重出一次;仍然不一致就**拒绝使用** —— 删掉这次抽的角度帧、不生成多视角图,该角色退回"单张正面照"渲染。这是刻意的"宁缺勿错":一张错的第二参考图会把成片主动往错的方向拉,比没有多视角更糟。

- 没配 VLM 时跳过校验,日志里会如实写「本次不做校验」,不会假装校验过;
- 想让多视角保持原有质量,建议在**设置页配好视觉模型**(智谱 glm-4.6v-flash 免费)。

已有资产自动复用;重新上传同名图后,条件缓存按内容指纹自动失效(不会用旧图渲染)。

### ④ 渲染出片(render)
引擎三选:
- **auto**(推荐):本地 ComfyUI 优先,不可用自动切云端 API
- **comfy**:本地(免费,768p,H3-Base)
- **api**:云端(按量计费,支持 768P/2K)

失败的单镜在故事板点 ⟳ 单独重渲;已完成的镜头在重复运行时自动跳过(断点续跑)。

**镜头级增强(镜头卡底部两个按钮,需本地 ComfyUI + 该镜已渲染完成)**:

- **局部重绘**:画面只有手部/道具/人脸等**局部崩坏**时用。SAM3 跨帧跟踪目标 → 裁出 → H3 重绘 → 羽化贴回原帧,只重生成那一块、其余画面逐帧保留;默认沿用该镜原 H3 提示词,你也可以只把崩坏部分的描述改对(其余保持不变,重绘的局部才与原画面接得上);需要 SAM3 跟踪模型(`checkpoints/sam3.1_multiplex_fp16.safetensors`,渲染前体检不含该项,缺失时提交后会报错);
- **音频驱动**:填入配音文件的**完整路径**(如 `C:\配音\shot3.wav`),重渲时**人物口型与动作节奏跟随这段音频**(H3 Ref2V 的原生音频条件),用于精确台词路线 —— 先把配音做成确定资产,再用它驱动画面。

两者结果都作为**独立文件**产出(`clips\shot_00N_maskfix.mp4` / `shot_00N_audiodrive.mp4`),**不覆盖原镜头** —— 比对满意后再自行采用;运行中或未渲染完成的镜头按钮为禁用态。

**渲染前体检**:本地渲染开始前会校验本次用到的 H3 节点是否齐备(缺插件时明确阻止并给中文提示,不会跑到一半才失败),并检测已知会破坏渲染的冲突插件(只告警,处理方式见 `docs/COMPATIBILITY.md`)。

### ⑤ 质检(qc)
时长/音轨/分辨率 + 抽帧亮度统计。黑屏或无音轨的镜头会判失败并给出原因。

**配音完整性**(2026-09-24 起):还会统计实测人声时长,与该镜台词的"应有口播时长"(按 4.5 字/秒)对照;不足六成即告警「疑似配音不完整」——提示台词被截断或整句没出声。重渲同一提示词同一 seed 大概率复现,真正要改的是**台词长度**或**拆镜**。

### ⑥ 合成成片(assemble)
拼接 + ASS 字幕烧录(台词金色/旁白白色)+ 响度归一(-16 LUFS)+ faststart。
「成片」页直接预览播放;「打开目录」取 final.mp4 / final.srt。

**音频质量处置**(「合成成片 ⚙」可调,2026-09-24 起):

- **镜间切点落在静音上**:叠化转场必须让出与画面重叠等长的一段音频,现在会按每个镜头的人声包络挑切点,让让出去的那段落在没人说话的地方 —— 不再每镜头尾各砍 0.25 秒、切掉台词尾巴(这是"配音不完整"最隐蔽的一条来源)。日志会写明「接缝切点:N/M 处完全落在静音」;
- **两遍响度归一**:先测量再线性增益,不会在对话与静音之间"抽气";滤波器不可用时自动降级并在日志说明;
- **音频净化(默认开)**:高通去隆隆声 + 频谱降噪去底噪/嘶声。H3 自己写在音景里的持续环境声压不掉 —— 那属于分镜侧的音景纪律(提示词已要求只写 1-2 句安静的底噪);
- **每镜音轨先补到与画面等长**、拼接中间轨走无损(flac),不为拼接多付一次有损压缩。

## 阶段独立管理

- 每个管线卡片可**单独运行**(改了提示词只重跑 render,改了字幕只重跑 assemble)。
- 每个阶段有**独立参数**(项目级快照,改全局设置不影响已有项目)。
- 底部 RUNTIME LOG 实时滚动全部管线事件(可清空/收起);历史也落在 `data\logs\manjux.log`。

## 常见问题

| 现象 | 处理 |
|---|---|
| 连接不确定 | 设置页各区块有「测试」按钮,一键验证 LLM/ComfyUI/MiniMax 连通性 |
| 单镜渲染失败 | 不影响后续镜头;阶段末汇总失败清单,故事板该镜头卡可见红色原因,⟳ 单独重渲 |
| LLM 未配置 | 设置页填写 BaseURL/Key/Model |
| ComfyUI 灯不亮 | 确认「根目录」含 `ComfyUI\` 与 `standalone-env\`;开启「自动代管启动」后重试(首启加载模型可达数分钟) |
| 云端任务失败 | 检查 API Key/余额;单镜重渲即可 |
| 镜头黑屏 | 提示词已带亮度护栏;仍黑屏多为音频 VAE 配置错误(设置页核对文件名) |
| 渲染超时 | 本地单镜上限 45 分钟;云端 20 分钟;失败重试或换引擎 |
| 合成失败 | 确认 ffmpeg 已装(PATH 可用) |
| 人物看着"油腻" | ①确认「剧本 ⚙」里**角色动漫化**是开的(默认开;关掉就走写实,皮脂高光会回来);②风格别选「真人实拍质感」;③仍然油,通常是提示词里写了强侧光/轮廓光/汗湿 —— 单镜重渲时把该镜提示词的打光描述改成柔和均匀光 |
| 角色像真人 / 担心侵权 | 「剧本 ⚙ → 角色动漫化」保持开启即按动画化渲染,并显式排除"真人照片脸 / 影射真实人物与演员";已生成的旧定妆照不满足就删掉资产让它重出 |
| 器物/灵宠/妖兽被渲染成人 | 到「资产定妆 · 详情」看那张角色卡的类型下拉:铜雀/木偶/机关人应是**物**,灵体应是**无实体**;改完点 ✨「重新生成」重出定妆照(改类型会自动作废旧角度图)。判定不准时优先检查描述里有没有写清"它是什么材质、什么结构" |
| 多视角和定妆照不像同一个人 | 这是校验拦截的正常结果:日志会写「多视角校验未通过…该角色本次按单张正面照渲染」。到「资产库」该角色卡片点**补全多视角**重生成即可;想减少发生概率,请配好设置页的视觉模型 |
| 配音不完整(台词没说完) | 分镜侧已按 4.5 字/秒自动抬镜头时长;仍不完整就说明台词整体过长 —— 在「剧本 ⚙」把镜头数调高、让每镜台词更短(越短越稳)。质检里会有「疑似配音不完整」告警指到具体镜头 |
| 成片有杂音/嘶声 | 确认「合成成片 ⚙」的**音频净化**是开的;日志里若写"单遍响度归一(两遍法不可用)"说明 ffmpeg 偏旧,建议升级 ffmpeg。持续的环境噪声来自分镜写的音景,可在单镜重渲时把 `overall_soundscape` 改简单 |

## 数据位置

全部产物在 `D:\Ai\ManJuX\data\projects\<项目>\`:
`clips\`(镜头)· `output\final.mp4`(成片)· `output\qc_report.json`(质检)· `plan\plan.json`(方案)。
删除项目(首页卡片 🗑)= 整目录删除,不可恢复。

## 云端用量与 2K 定稿

- 云端仅在「引擎=api(含镜头级分派)」或 2K 定稿时调用;auto 模式本地可用时不动云额度。
- 2K 定稿入口:成片页「升级 2K」按钮(整片)/ 镜头卡 ⟳ 下拉「云端 2K 定稿」(单镜)/ 合成调优开启「云端 2K 定稿」(合成后自动)。
- 源视频须符合 H3 768P 规格(短边 768、含音轨、≤50MB),否则预校验会拦截。

## 本地 2× 放大

本地 ComfyUI 引擎已实现两条 2× 放大链路 —— **LTX 隐空间放大**(含 8n+1 时间轴补齐、解码后裁回原帧防时长漂移)与 **ESRGAN 帧级放大**,两条都保留原音轨(放大只提升画面,声音原样复用);所需模型已就位。

**入口**:故事板镜头卡 → 「2× 放大」下拉。两项分别是「帧级 2×(最省依赖 · 硬边细字更保真)」与「隐空间 2×(更快 · 实拍质感更好)」。

隐空间那条会弹一个确认框,里面**已经填好默认的 VAE 文件名**(LTX2_video_vae_bf16.safetensors)—— 直接用默认值回车即可,只有你另装了别的 VAE 才需要改;留空也等于用默认值。

**两条链路怎么选(2026-09-24 用真实漫剧素材实测)**:

| | 帧级(4x-UltraSharp) | 隐空间(LTX VAE + spatial-upscaler) |
|---|---|---|
| 速度快慢 | 慢:768P 源片约 **3.8 秒/帧**(48 帧 ≈ 3 分钟) | 快:同素材 48 帧 ≈ **18 秒** |
| 画面忠实度 | 逐帧真超分,**片内硬边细字(字幕、路牌小字)能保住笔画** | 学习式视频 VAE(32× 空间压缩 + 随机解码),**硬边细字会被抹软** |
| 质感纹理 | 干净、锐利 | 布料纹理、缝线、材质底板更自然(实测同一帧明显优于源片) |
| 依赖 | 只要一个 `upscale_models/` 权重 | 还要 LTX 视频 VAE(2.3 GB,已随文档清单备齐) |

- **片内有字幕/小字** → 走帧级(隐空间会把字糊掉);
- **追求质感、赶时间** → 走隐空间;
- 两条都会把 `ImageUpscaleWithModel` 的显存吃满吗?不会 —— ComfyUI 内部按 512 瓦片处理,且 OOM 时自动把瓦片减半(最低 128),实测 768P/48 帧无溢出。

**要点**:
- 只提升分辨率,**音轨沿用源片、时长不变**;放大是逐帧后处理,帧数取自源产物而非项目当前参数,所以不会因为改过配置而让时长漂移。
- 结果作为**独立文件**产出(`clips/shot_00N_upscale2x.mp4`),原镜头不动 —— 比对满意后自行替换。
- 需要本地 ComfyUI 可用;完成后会自动释放显存(队列有活或管线在跑时内部自己会让路)。
- **提交前会先体检权重**:缺哪个文件、该放进 `models/` 下哪个目录,报错里直接写明(此项为 2026-09-24 补,此前缺文件要等 ComfyUI 执行到那个节点才以原始报文抛出)。

## 数据安全

- 渲染中关闭窗口会弹二次确认,防止误关中断管线;
- 全部事件日志落 data/logs/manjux.log(超 10MB 自动归档 .old)。

## 资产库(跨项目复用)

- 顶栏「资产库」页管理全部已入库资产(按复用次数排序);
- 入库来源:Krea-2 自动生成 / 手动上传,资产阶段结束自动完成;老项目重跑「资产定妆」会把已有资产回填入库;
- 新项目遇到**同名**角色/场景自动引用库图(资产页显示「库复用」徽标),不重复生成、天然形象一致;
- 想强制重新生成:删除库条目或换角色名。
- **点击卡片看详情**:弹窗里是该资产的**全部图片**(定妆照 + 转台图等关联图;若同目录存在 `_view_*` 多视角原图也会一并收进来,每张按文件名标注用途,点击可放大)、中文描述、英文提示词、来源(Krea-2 生成 / 上传)、首次入库项目与**已被多少个项目复用**;
- **重抽(同角色换一张)**:描述与提示词原样不动,只换随机种子重新生成定妆照 —— 与顶部「抽卡」不同(抽卡拉的是一个**全新角色**,重抽是对当前这张不满意再摇一次);重抽会一并清掉旧的多视角与转台图(它们对应的是上一张定妆照,已失效)。上传入库、没有英文提示词的条目无法重抽;重抽需本地 ComfyUI(约 1 分钟);
- 弹窗内也可直接**删除该资产**。

## VLM 智能审片

设置页「视觉大模型」配置(默认智谱 glm-4.6v-flash,免费,填 Key 即用,可点「测试」验证);项目「质检 ⚙」开启后,质检阶段会抽帧送视觉模型判分(0-100 + 问题清单 + 中文重渲建议),报告并入 output/qc_report.json。

## 镜间连续接缝(MotionContext)

项目「渲染出片 ⚙」开启后(仅本地 ComfyUI 引擎):每镜尾部 22 帧音画钉入下一镜,镜头衔接更连贯;渲染长度自动补偿,产物自动裁掉钉入头。上一镜为云端产物或旧渲染(无接缝存档)时该镜自动降级普通渲染,不报错;重渲某镜后建议后续镜头一并重渲保持链一致。

## 剪辑素材包导出

「成片」页「导出剪辑素材包」:按镜序命名的片段 + 成片 + 时间轴对齐 SRT + 导入说明,打包为 output/剪辑素材包.zip;剪映导入步骤见包内说明(通用素材方案,任意剪映版本可用)。


## 整本小说与批量产线(v0.28+)

「小说」页导入整本书(多章节目录或单文件,含「封面」文件夹自动识别为系列封面)→「一键创作」自动查重并拆集:提交即出现书级占位卡(AI 拆集中·已建 N 集实时计数),逐集子项目(书名·第NN集·标题)实时出现;完成后点「批量产线」逐集自动跑全流程,中断可续(已成片集自动跳过)。剧集在「剧集合集」弹窗里单集管理;同名角色/场景自动复用资产库定妆,系列形象一致。

**拆集规则(2026-09-12 定稿:严格一章一集)**:

- **一章正好一集,集数 = 章数** —— 既不把一章拆成多集,也不把两章压进一集;
- **集名 = 章名** —— 集标题直接取该章标题原文;若模型自起了文艺标题,代码会用章名强制覆盖,保证「章 → 集」可对账;
- **镜数按内容给足、不设上限** —— 一章里事件多就多给分镜(密的章 15-30 镜是正常的),用镜头数体现细度,而不是靠多拆集。

拆完会做两项核对:检测「一章被拆成多集」并告警(只提示建议重拆,**不会自动合并**);统计各集覆盖的章号,缺章时点名列出 —— 缺章在末尾可直接续建,缺在中间可重新提交「一键创作」触发自动补缺(会删除缺章位置之后的分集并重拆续接,保留分集与资产库不动;若缺的是最前面几章则代价很大,警告文案会明确交代,先核对是否只是标注漏项)。

## 运行日志与一键停止

底栏日志条实时滚动全局事件;点开为悬浮窗(默认右下角,标题栏可拖动、右下角手柄可调大小,不挡主界面)。悬浮窗右上角**一键停止**:点击弹二次确认后停止当前运行中的管线(已完成阶段保留,修复后可续跑)。运行日志只收录应用内部操作与管线渲染事件;版本检查等远程网络状态在管理页查看,不入日志流。

## 批量管理与全选

首页(按书/按项目管理单元)、作品库、资产库均支持批量勾选删除,批量工具栏含**全选/取消全选**一键切换;整部小说按书勾选即全部分集一并管理。

## 图片上传与拖放

角色定妆照/场景参考图/封面/资产库自建角色支持**点击选择**与**拖入**两种方式;拖入后立即显示缩略图预览,上传结果如实反馈(大图自动压缩,桌面端经 wails 原生拖放通道,不受浏览器安全限制)。

## 显存释放

管理页「释放显存」:卸载 ComfyUI 已加载模型,反馈真实显存变化(如「18.2 GB → 2.1 GB」);任务执行中卸载会延后到当前任务结束,引擎未运行时如实提示(显存随进程释放,无需操作)。
