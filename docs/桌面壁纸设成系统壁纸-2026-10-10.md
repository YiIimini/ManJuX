# 桌面壁纸设成系统壁纸：单图 + 平台自己的幻灯片（2026-10-10）

用户原话：「**桌面壁纸可以管理设置当前系统桌面壁纸（幻灯片、单图等相关功能）**」。

这一轮把壁纸库里的**桌面壁纸**从"一张好看的图"变成"**本机真正的桌面壁纸**"：点一下立刻生效，
再给一个"幻灯片"（按间隔自动换）。

---

## 一、先取证：Windows 自己那套幻灯片，我能不能写？（结论：不能猜着写）

在本机（Windows 10.0 **build 26200**）读出来的三处事实：

| 位置 | 值 |
|---|---|
| `HKCU\Control Panel\Desktop\WallPaper` | `D:\Ai\Datas\ManJuX\data\壁纸\深海鲸鱼娘-银金游弋-备选-3440x1440.png` |
| `HKCU\...\Explorer\Wallpapers\CurrentWallpaperPath` | `D:\Others\图片\217de450…jpg`（**与上一行不是同一个**） |
| `HKCU\...\Explorer\Wallpapers\BackgroundType` / `SlideshowSourceDirectoriesSet` | `2` / `1` |
| `HKCU\Control Panel\Personalization\Desktop Slideshow` | `Interval=1800000`（30 分钟）、`Shuffle=1`、`LastTickHigh/Low` |

关键那条：**`SlideshowDirectoryPath1` 不是路径**。把它按 base64 解开是 **354 字节二进制**
（`hex 头 80500503…`，里面是 shell item 结构，没有可读路径）：

```
gFAFA8BUg/E0gouOpBhoYjAArADMdmBAvQkOcBAAAAA…
  → bytes=354, hex(0..24)=80500503c05483f134828b8ea41868623000ac00cc766040
```

⇒ **照猜去写那个值，就是把用户自己的幻灯片配置弄坏**（而真机里它**正在用**：30 分钟、随机、
源目录 `D:\Others\图片`）。所以本轮的决定：

- **单图**：走 Windows 自己的接口 `SystemParametersInfoW(SPI_SETDESKWALLPAPER)`；
- **幻灯片**：**由平台自己轮换**（间隔 + 顺序/随机），**一个字节都不动** Windows 那套配置。

> 顺带说明：Windows 确实有文档化的 COM 接口 `IDesktopWallpaper::SetSlideshow`，但本仓库不引新依赖，
> 用它得手搭 COM 虚表调用；真要走系统级幻灯片，得**先有把握写对那个二进制**（本轮没做，如实记边界）。

## 二、做出来的东西

### 后端（`internal/server/`）

| 文件 | 内容 |
|---|---|
| `wallpaper_desktop.go` | 口径与状态机：`normDeskMode`/`normDeskInterval`（夹 [1,1440] 分钟，缺省 30）/`deskOrder`/`deskPosAfter`/`deskState`/`deskUpdate`/`deskSave`/`deskRotateOnce`/`deskStartRotation`/`deskStopRotation`/三个 handler |
| `wallpaper_desktop_windows.go` | `//go:build windows`：`SPI_SETDESKWALLPAPER` / `SPI_GETDESKWALLPAPER`（user32，`syscall.NewLazyDLL`）+ `regDWORD`（**只读**注册表） |
| `wallpaper_desktop_other.go` | `//go:build !windows`：如实说「本平台不支持」（`desktopWallpaperSupported() == false`），不假装做过 |

三个接口：

- `GET /api/wallpapers/desktop` → 状态：`supported / mode / file / last_set / interval_min / shuffle / order_label / running / current / current_in_library / current_name / count / note / native_note`
- `POST /api/wallpapers/desktop/apply` `{file, mode: single|slideshow, interval_min, shuffle}` → 设上去
- `POST /api/wallpapers/desktop/stop` → 停轮换（系统停在最后一张）

**几条自己给自己定的纪律**（每条都有门）：

1. **设完读回来对齐**：单图设完不是报「已设置」就完事，界面显示的是 `SPI_GETDESKWALLPAPER` 读回来的那张
   （真机可验，见下）。
2. **失败不许写状态**：`s.deskSet(p)` 成功之后才 `deskUpdate(...)` —— 否则界面会说「已设为壁纸」，
   而系统上什么都没变（顺序被门钉住）。
3. **只有桌面分类能设**：手机壁纸是竖版（9:16），设到横版桌面上会被裁两侧 ⇒ 400 并说清去哪儿出横版。
4. **注册表只读**：平台不写 Windows 那套幻灯片配置（门禁 `RegSetValueEx`/`RegCreateKeyEx`/`RegDeleteValue`）。
5. **系统自己那套幻灯片如实提醒**：`native_note`（只读 `Interval`/`Shuffle` 得来）——
   它可能按自己的节奏把平台设的图换掉，与其等用户犯疑，不如平台先说清。
6. **边界写在界面上**：轮换**只在平台运行期间生效，退出平台就停在最后一张**；
   平台重启后**不会**自己接着轮（状态回显 + 一句话告诉你点「开始轮换」继续）。

### 前端（`frontend/src/views/WallpapersView.vue`、`store.js`）

- 桌面分类顶部多一条「系统壁纸」栏：现在系统上是哪张（库里的就显示文件名）、间隔（分钟）、随机、
  「开始轮换」/「停止轮换」，以及 `note` 与 `native_note` 两句话；
- 网格里每张桌面壁纸多一个「**设为壁纸**」；当前系统壁纸那张带「系统壁纸」角标；
- 手机分类**不给**这些入口（后端会 400，前端不该让用户白点一次）——门的判据咬**按钮标记**
  而不是那几个字（`停止轮换` 四个字也出现在 JS 提示文案里，只数文字的话把按钮删了照样绿）。

## 三、真机实测（`TestZZProbeWallpaperDesktopLive`，`MANJUX_LIVE_PROBE=1`）

```
① 当前系统桌面壁纸：D:\Ai\Datas\ManJuX\data\壁纸\深海鲸鱼娘-银金游弋-备选-3440x1440.png
   文件在盘上：5156431 字节
② 设完读回：D:\Ai\Datas\ManJuX\data\壁纸\深海鲸鱼娘-银金游弋-备选-3440x1440.png   ← 逐字一致
③ 系统自己那套幻灯片：注意：Windows 自己那套幻灯片还配着（每 30 分钟、随机）——它可能按自己的节奏
   把平台设的图换掉。平台不碰那套配置；要它别抢，去 设置 → 个性化 → 背景 里关掉幻灯片
```

- 探针**设的是当前那一张** ⇒ 桌面观感零变化，同时验证了「设」这条链真的通（0.07 秒）；
- 探针**逐个核对** `WallpaperStyle`/`TileWallpaper`/`BackgroundType`，被 SPI 改动就报错 —— 这次**一个都没变**；
- 读取用的是 `SPI_GETDESKWALLPAPER`（不是读注册表）：它回的正是用户 `data\壁纸\` 里那张，
  与 `Wallpapers\CurrentWallpaperPath` 的 `D:\Others\图片\…` **不一致**（说明那个键记的是别的东西，
  不能拿来判"当前壁纸是哪张"—— 这也是为什么本轮坚持用 SPI 读回）。

### 反向验证当场咬出的两个真问题（都已在轮内修掉）

1. **自死锁（生产也会有）**：`deskRotateOnce` 在**持有 `deskMu` 时**调 `deskSeqBuild`，而后者要读状态
   （同一把锁）⇒ Go 的 mutex 不可重入 ⇒ **卡死**。只在"序列走完要重排"那一步才触发，所以最初那批门
   （只等到第 3 次）全绿；D3（让轮换一直跑）把它逼到 **600 秒超时**才报栈。修法：重排挪到锁外，
   并且**门自己跨过一整轮**（等到第 4 次 = 回到 a）—— 这条死锁现在被门自己咬得住。
2. **门的判据太软**：门 9 原来数 `停止轮换` 四个字，而那四个字也出现在 JS 的提示文案里
   ⇒ 把按钮删了照样绿。改成咬**按钮标记**（`>停止轮换</el-button>` 恰 1 次）。

## 五、边界（如实说）

- **幻灯片走的是平台自己的轮换**：只在平台运行期间生效，退出平台就停在最后一张；
  平台重启后不会自动接着轮（点「开始轮换」继续）。要系统级幻灯片，得用 Windows 自己的设置 ——
  平台**不碰**那套配置（那个二进制没把握写对，见第一节）。
- 本机 `data\壁纸\`（用户自己那份壁纸，16 个文件，当前系统壁纸就出自这里）**不在**壁纸库目录下，
- **单图只认桌面分类**（竖版设桌面壁纸会被裁）；想在桌面上用竖版图，得先改这条口径（一行的事）。
- **没做**：多显示器分别设壁纸（`SPI_SETDESKWALLPAPER` 只设主背景）、开机自启的轮换、
  Windows 原生幻灯片的驱动（COM 那条路）。
- 本机 `data\壁纸\`（用户自己那份壁纸，∎16 个文件，当前系统壁纸就出自这里）**不在**壁纸库目录下，
  这一轮没有把它并进库里（要并就得用户点头，见交付说明）。
- 真机验证只覆盖「设当前那张 ⇒ 读回一致」（观感零变化）；**"换成另一张"没有在真机上跑**
  （那会改用户的桌面观感，得用户自己点一次）。
