# 技能侧（manju-novel）提示词改动 · 电影级口径

> 起因：用户 2026-09-26「视频渲染不能是电影级的画面吗？现在渲染的真的垃圾」+「渲染内容漂移、角色定妆照不一致」。
> 平台侧已实测的部分：**40 集里同一角色的 `image_prompt` 逐字一致**（14 个角色、每个只有一个长度值、开头全一致）——
> 所以"角色不一致"不是脚本写飘了，技能侧要背的是下面这两笔：**风格口径自相矛盾**与**台词未与画面隔离**。

---

## 改动 ①（主改）：全片风格口径 `--style` 默认值

**位置**：`scripts/manju_plan.py:2686`

```python
p.add_argument('--style', default='PHOTOREAL 3D CINEMATIC WORLD, SEMI-STYLISED ANIME-ADJACENT FACES, matte finish')
```

### 为什么必须改

这一串被**逐字注入**每个角色的 `image_prompt`、场景图和每一镜的提示词。它现在同时要求两件互相打架的事：

- `PHOTOREAL 3D` → 写实向，但 "3D" 这个词本身就把模型推向**塑料质感的 CG 渲染**
- `SEMI-STYLISED ANIME-ADJACENT FACES` → 又要动漫脸

模型只能给折中产物：**3D CG 脸**——皮肤油亮、头发成块、光影平。这正是抽帧看到的画面，也是"不够电影级"的根子。

### 改成（可直接粘贴）

```python
p.add_argument('--style', default='LIVE-ACTION CINEMATIC PHOTOGRAPHY, 35mm anamorphic lens, shallow depth of field with true optical background falloff, natural film grain, physically-based skin and fabric texture with visible pores and fibre, motivated key light with strong shadow falloff, teal-and-amber colour separation, filmic contrast curve, no cartoon or anime styling, no plastic 3D-render look')
```

改动要点（逐条说明为什么）：

| 元素 | 作用 |
|---|---|
| 去掉 `3D`、改 `LIVE-ACTION CINEMATIC PHOTOGRAPHY` | 3D 这个词是塑料感的直接来源 |
| 去掉 `ANIME-ADJACENT` | 与"电影级"直接冲突，二者只能留一个（你说要电影级） |
| `35mm anamorphic lens` / `shallow depth of field` | 给模型**镜头语言**：景深分离主体与背景，这是"电影感"最大的一笔 |
| `physical... skin and fabric texture with visible pores and fibre` | 直接对着"塑料皮肤/成块头发"下药 |
| `motivated key light with strong shadow falloff` | 电影布光（明暗对比），替换现在的平光 |
| `teal-and-amber colour separation` / `filmic contrast curve` | 调色基调。若你更喜欢别的调（冷青、暖橘→青蓝等），改这两个词即可 |
| `natural film grain` | 胶片颗粒，去掉"数位干净感" |
| 末尾两个 `no ...` | 给模型一条明确的禁止线 |

> 备选（若你更想要"动画电影"而不是"真人电影"）：
> `STYLISED 2.5D ANIMATED FEATURE FILM, painterly backgrounds, consistent character sheets, cinematic lighting with strong shadow falloff, filmic contrast, subtle grain, no photoreal skin, no plastic 3D-render look`
> —— 二选一，**不要混着写**，混着写就是现在这个结果。

## 改动 ②（配套）：台词与画面文字隔离

**现状**：台词以 `<d>[Chinese]台词</d>` 形式进提示词（`manju_plan.py:623` 等）。这是**给 H3 做原生配音的条件**，必须保留中文原文。
**问题**：4 步蒸馏下，模型会把方括号里的中文字**当成要画的内容**——这就是"有的画面还有字幕"。

**改法**：在**含对白的镜头**的提示词里，紧跟对白段补一条英文条款（音频专用声明）：

```
AUDIO-ONLY DIALOGUE: the <d>[Chinese]…</d> lines above are SPOKEN lines for the voice performance only.
They must NEVER be rendered as written text — no subtitles, no captions, no on-screen text, no signage,
no handwriting, no lettering of any kind anywhere in the frame, in any language.
```

画外音那句已有 `on-screen lips remain completely closed (voice-over, not dialogue)`（`:607`）——**保留**，它是对的。

平台侧也会在收尾块注入 `No on-screen text, no subtitles, no watermarks, no logos`（`internal/pipeline/prompts.go`），
但它是**通用兜底**、压不住正文里的中文，所以这条得在技能侧贴身写。

## 改动 ③（可选，平台已兜底）：角色定妆照取景写成竖版

**现状**：角色卡尾部是 `plain neutral background, upper-body framing, front-facing, 16:9`。
**实际**：平台会**剥掉**这些人像取景短语再按类型追加取景（`pipeline/prompts.go` 的 `sheetFramingWords`/`rewriteSheetFraming`），
所以出图是 **832×1248（2:3）**、不是 16:9——平台这层是对的。

**但**成片画幅是 **768×1344（9:16）**，参考图与成片比例不一致，模型要重新诠释构图。
若想从源头对齐：把最后一个 `16:9` 改成 `9:16 vertical framing`（并让平台不改写这一项）。

## 改完必须重出（否则不生效）

`plan.json` / `_pool.json` 里的 `image_prompt` 与 `style` 是**固化**的——只跑 emit **不会**更新它们（技能脚本 `:2527` 自己的注释）。
所以改完默认值后要重出脚本包：

```
python C:\Users\Administrator\.dsh\skills\manju-novel\scripts\manju_plan.py build ^
  --project D:\Ai\小说\求你们骂我 ^
  --out D:\Ai\小说\求你们骂我\漫剧脚本 ^
  --episodes all --llm-en
```

（`--llm-en` 按 24 镜分块补英文本句，是既定的重出姿势；走技能自己的专用 key。）

**验收口径**（改完自查，别靠感觉）：
1. 抽一集 plan.json，确认 `style` 字段已是新串、且**不含** `3D` / `ANIME`；
2. 同一集里含对白的镜头，提示词必须同时出现 `AUDIO-ONLY DIALOGUE` 与 `<d>[Chinese]`；
3. 角色卡 `image_prompt` 末尾不再有 `16:9`（若做了改动 ③）。
