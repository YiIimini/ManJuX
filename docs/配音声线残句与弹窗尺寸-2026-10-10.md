# 配音「声不对人 / 重复配音」+ 所有弹窗不许超出父级窗口（2026-10-10）

用户原话：「配音还是存在问题，版不对人，重复配音，进行排查处理，别把其它地方改错了；
另外小说封面重制弹窗窗口固定大小，别超过父级窗口，所有的弹窗都需要这样要求」。

这一轮**只动两处**（用户明确要求别改错别的地方）：配音的**声线绑定**一处 + 弹窗的**全局尺寸**一处。

## 一、配音：先取证（用平台自己的仪器，不猜）

对象是用户**刚在渲的那一集**：`data/projects/离婚后，千亿前夫跪求复合/离婚后，千亿前夫跪求复合·第01集·签字，滚出顾家`
（11 镜；17:43–18:21 渲出 shot_001~004）。三个探针都改成可指向**当前在查的那一集**
（`$env:MANJUX_PROBE_PROJECT="<项目 id>"`；此前三个探针都把项目 id 写死在那个已被删除的《顺其自然》上，
不换代码就查不了 —— 这也是一条"工具不好用就没人用"的账）。

### 1）「声不对人」的根因：装配把两句**互斥的声线**同时写进了音频条件

`zz_probe_voice_live_test.go`（走**真实装配**）打印出来的引述（改前）：

```
镜 3 顾母  <Subject 1> (S3), an older woman in her sixties with a sharp, rasping, 顾母 says in An elderly, sharp, nagging female voice…:
镜 2 苏雅  <Subject 2> (S2), twenties, soft, drawling, 苏雅 says in A sweet, breathy, sing-song young female voice…:
镜 8 苏雅  <Subject 2> (S2), a young woman in her twenties with a soft, drawling, smiling voice, 苏雅 says in …
```

也就是说：**卡上权威声线（右侧）与模型自编声线（左侧）都在**，而且左扩那条规则
（"每个词都在声线词表里才吃"）**一遇到表里没有的词就停下** —— 真机命中 `older / rasping / drawling / smiling`
四个词，于是 11 镜里有 4 句带着这种残句。H3 拿这段文字当**音频条件**（不是契约），
两句互相矛盾的声线同时在场时出来的是哪一种**没有保证** ⇒ 用户听到的就是「声不对人 / 这一镜换了个嗓子」。

**修法**（`internal/pipeline/voice_rebind.go`，只改这一段判据）：不再靠穷举词表（穷举永远漏词），改成
"**先找性别/年龄证据，再往两边吃**"：

1. 老规则照旧先走一遍（整段都是声线词 ⇒ 吃）；
2. 剩下的尾部里找一段**性别/年龄证据**（含性别/年龄词、且不含画面词、且不含主体标记）；
3. 从证据段**往右**吃到尾（词表缺词造成的残段才算数：无画面词、无主体标记、≤8 个词）；
4. 往左仍只吃"整段都是声线词"的段 —— **画面描述一个字都不许动**；
5. 找不到性别证据 ⇒ **一个字都不动**（宁可漏删一处残留，也不删画面内容）。

**真机复核（同一条探针，改后）**：15 句台词**全部**收成一句声线，且逐字等于角色卡原文
（`<Subject 1> (S3)顾母 says in An elderly, sharp, nagging female voice…`），
模型自编的 `older woman / rasping / drawling / smiling voice` **一处不剩**。

### 2）「重复配音」：平台**判了、也重出过**，但收尾文案只说"音色"，用户读不出来

`internal/qc/zz_probe_speech_live_test.go` 对刚渲的 4 个片段跑 ASR 对账（真机原话）：

```
镜头 1  [1.58-5.30] 林婉,签字吧,别逼我让律师发函。                        对账 sim=0.92 times=1   ✔
镜头 2  [2.52-5.54] 芽芽回来了﹔她才是顾家少奶奶。 / [6.28-9.40] 姐姐﹔五万块﹔够你买房了。  ⚠ extra（音轨里多了一句剧本没有的话）
镜头 3  [0.00-4.42] 赶紧签﹔别耽误我抱孙子﹔我笑你们有眼无珠。              ✔（两句都在）
镜头 4  [0.05-5.05] 本来就是我买的,这整栋别墅,三千万的别墅。              ⚠ missing（林晚那句被念成了倒装+混入顾母的词）
        [5.47-8.29] 就凭你,三千万的别墅?                                   ⚠ repeat（**同一句被念了两遍**）
```

⇒ 「重复配音」是**真的**（镜 4），H3 把台词当条件不保证照做（平台 2026-10-08 就记过这一条）。

处置链**本来就在**（`voice_check.go`：判负 ⇒ 换种子重出，最多 2 轮；`repeat/extra` 都算判负），
问题在**两处口径**：

- **收尾只说"音色"**：`stages_render.go` 原来写「仍有 N 镜的**音色与角色卡不符**」——
  用户读完以为平台**没看见**"重复念"这件事（其实判了、也重出过）⇒ 改成点名两类：
  「音色与角色卡不符**或语音念重了/多念了**（音色＝卡上男/女声念成了另一种嗓子；语音＝重复配音/多念）」。
- **声线残留会拖累服从度**：残句去掉后，H3 看到的是**一句**干净声线（上面第 1 条），这是能确定性改善的那一半。

**如实说**：这一镜（镜 4）是**两轮重出都没修好**的那一类（H3 顽固），平台会保留最后一次产物并播报；
重复配音**不能靠提示词根治**，只能"判出来 + 有界重出 + 如实摆出来"。**本轮没有重渲验证**（ComfyUI 不在跑）。

## 二、弹窗：所有弹窗一律不许超出父级窗口

用户点名封面重制弹窗（固定 `width="880px"`，小窗口上直接顶出去），并要求**所有**弹窗都这样。

修法：**一处全局收口**（`frontend/src/style.css` 的**元素级** `.el-dialog` / `.el-drawer`），
不是逐个弹窗加类名 —— 新增弹窗不需要谁"记得"加，也一样被夹住：

```css
.el-dialog { max-width: calc(100vw - 32px); max-height: calc(100vh - 48px); display: flex; flex-direction: column; overflow: hidden; }
.el-dialog__header, .el-dialog__footer { flex: none; }
.el-dialog__body { min-height: 0; overflow: auto; }   /* 高度夹住之后内容必须在弹窗内部滚，否则按钮被静默裁掉 */
.el-drawer { max-width: calc(100vw - 32px); max-height: calc(100vh - 32px); }
```

封面重制弹窗**保留定宽**（用户要的是"固定大小、但不超父级"），夹住由这条全局规则负责。

## 三、门与反向验证

| 门 | 钉住什么 |
| --- | --- |
| `TestBindLineVoicesEatsModelVoiceLeftovers`（pipeline） | 夹具＝**真机那 3 条原话**（顾母 older/rasping、苏雅 twenties/drawling、苏雅 young woman…smiling voice）：卡上声线逐字在、模型自编声线一个字不留、**一句台词恰好一个声线子句** |
| `TestStripGenderTailKeepsPictureWords`（pipeline） | 反面针：性别证据右边只要还有画面段（one hand / table）就**一个字都不动**；纯声线残段必须吃掉 |
| `TestRetryExhaustedMessageNamesBothKinds`（pipeline） | 重出用满的收尾文案必须同时点名"音色"与"语音念重了/多念了（重复配音）" |
| `TestAllDialogsAreBoundedByParentWindow`（server） | 全局 `.el-dialog` 有 max-width/max-height + 头脚固定/主体滚 + `.el-drawer` 同样夹住 + 既有日志窗夹法不许回退 |
| `TestCoverRedoDialogKeepsFixedSize`（server） | 封面重制弹窗**保留定宽**（不是改成自适应） |

**反向验证 7/7 全红**（`scratch/reverse_verify_voice_dialog.ps1`）：干掉新判据 / 画面词不再受保护 /
收尾文案退回只说音色 / 弹窗不夹高度 / 主体不滚 / 抽屉不夹 / 封面弹窗改成自适应 —— 七条各自都让对应门变红。

## 四、边界（没做到的就说没做到）

1. **同镜男女混合的音色**仍然**判不了**（真机镜 2 就是这一类：整镜基频混在一起 ⇒ 平台如实记"不判"）。
   要判得按 ASR 时间段**逐句归属**再分别量基频 —— 判据可行（`asr.Segment` 有时间点），**本轮没做**，
   这是「声不对人」剩下的一半（另一半＝上面的声线残句，已修）。
2. **重复配音不能根治**：H3 不听就是不听；平台能给的是"判出来 + 换种子重出 2 轮 + 如实播报"，
   真机镜 4 两轮都没修好。要根治得换配音方案（平台外置 TTS 那条路）。
3. 本轮的配音修复**没有重渲验证**（ComfyUI 不在跑）：改的是**提交版提示词**（探针已逐句核对），
   出图那一侧的效果只能等下一轮真机渲染。
4. 弹窗的修复是 CSS 层的：`vite build` 通过了，**但我没在真窗口里量像素**（需要起 app）。
