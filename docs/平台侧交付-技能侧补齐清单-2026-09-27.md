## 1. S1（P0）角色卡没填 `image_prompt` / `board_prompt`

**实测**：`素材/卡片.json` 与 `分镜明细.json` 内嵌的 `characters[]`，**两份都是空串**：

```text
char_01 沈砚·一品   image_prompt=0 字   board_prompt=0 字
char_04 苏晚        image_prompt=0 字   board_prompt=0 字
char_02 阿婆        image_prompt=0 字   board_prompt=0 字
… 30 张全部如此
```

**对照**：同一个文件里 `scenes[]` **0/8 缺**、`props[]` **0/15 缺** —— 所以不是"字段没产出"，
是**角色这一类没写进去**（你们 markdown `素材/角色卡.md` 里那两个 ` ```text ` 块是成品，逐字搬过来即可）。

**为什么要紧**：`characters[].image_prompt` 是平台生成**定妆照/转台/三视图板**的输入。
空着的时候平台只能：① 退回按 `description` 现编（**跨镜身份一致性直接掉**），
或 ② 回退去解析你们的 markdown 角色卡（平台**确实做了这个兜底**，`internal/project/char_cards.go`，
但那是兜底、不是设计——你们自己的口径写的是"**JSON 优先、markdown 供人读**"）。

**要的形态**：`characters[].image_prompt` = 「① 定妆」那个 ` ```text ` 块的正文；
`board_prompt` = 「② 三视图细节板」那个块的正文（逐字，**不要**带围栏与标题行）。

**自证**（你们那侧跑）：

```python
import json
d = json.load(open(r"<项目>\分镜\分镜明细.json", encoding="utf-8"))
bad = [c["id"] for c in d["characters"] if not (c.get("image_prompt") or "").strip()]
print("缺 image_prompt 的角色卡：", bad or "无")
```

## 2. S2（P0）`view` 串要**逐字写进提示词正文**

**实测**（最要紧的一条）：

```text
view 非空：1693 镜
其中「h3_prompt 里能找到该串」：0 镜        ← 100% 不同源
```

**例**（`第01集 S3`，`view = "telephoto compression"`）：提示词的 `[Shot 1]` 行写的是

```text
[Shot 1] medium close-up, … framed at eye-level, Shen Yan (沈砚) at left foreground..
```

—— 写的是**自然语言机位**（`framed at eye-level`），而**不是**官方那 9 条里的逐字串。

**为什么要紧**：官方格式与平台契约查的都是**提示词正文**（`PlanViewIn(sh.H3Prompt)` 在正文里找那 9 条之一），
不是 `view` 这个字段。字段填了、正文没写 ⇒ 平台侧那道"该有视角却没写"的门会一直报
（现在报 **224** 镜 = 建立镜头 150 + 远景/全景 74；其余小景别按裁定 A 允许留空，不判）。

**要的形态**（两边同一句口径，与你们 `view` 字段的取值**逐字一致**）：

```text
[Shot 1] 中景, <机位那一句改成官方串>, …        ← 该有视角的镜（建立/远景/全景）必须写
[Shot 1] 近景, …（小景别可以完全不写视角串）      ← 裁定 A 允许留空
```

**自证**：

```python
OFFICIAL = set(json.load(open(r"<项目>\分镜\分镜明细.json", encoding="utf-8"))["shots"][0].get("view_official_vocab") or [])
d = json.load(open(r"<项目>\分镜\分镜明细.json", encoding="utf-8"))
bad = [s["id"] for s in d["shots"]
       if (s.get("view") or "").strip() and s["view"] not in s["h3_prompt"]]
print("字段有 view 但正文没写该串的镜：", bad or "无")
```

（`view_official_vocab` 每镜内嵌了那 9 条，直接用。）

## 5. S5 / S6 / S7（P1–P2）内容层的三条

这三条**不是格式问题**，是内容编排，平台侧只报数、由你们（或 LLM 导演）判断：

| 判据 | 实测 | 说明 |
|---|---|---|
| 建立镜头不许特写 | **9** 个 | 小景别当建立镜头 = 观众第一次看见一个地点却没被交代地点。换远景/全景/中景 |
| 连续同景别 ≤6 | **18 / 40 集**超限 | 一长串同景别 = "像同一台机器拍完整集"。加机位/景别变化即可 |

> 口径提醒（免得两边对不上）：**开篇与收尾的强钩子**在平台侧是
> `visual-joke / reversal / reveal / suspense / tender` 五选一（官方 STEP 5.5 检查 1 后半句），
> 而 `setup` 与 `callback`（**callback 是"密度型"强钩子，但不是"开篇/收尾型"**）都不算。
> 你们词表里那 10 个是官方原表，保持不变即可。
