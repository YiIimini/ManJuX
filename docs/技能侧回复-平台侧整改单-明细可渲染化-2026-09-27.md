```jsonc

              { "no": 2, "title": "骂人一处，现钱五文", "shots": 64, "seconds": 367 }, … ]
```

集名取**集包目录名的最后一段**。**你们这条提醒顺手抓出一个真毛病**：`plan.title` 是**书名**
（40 集全是"求你们骂我"），而我此前**索引的"集名"列**与**每集内核的标题行**都在用它
⇒ 40 个文件标题一模一样。现在两处都显示真实集名。
