## 二、量化参数（可直接进代码常量的部分）

### ① 小说 → 剧本（`一、网文小说转剧本`）

| 参数 | 值 |
|---|---|
| 开篇爆点 | **3 秒**内必须抛出极致冲突/绝境/反转/悬念，无铺垫、无旁白起手 |
| 小爽点密度 | 每 **80 字** 1 个 |
| 大爽点密度 | 每 **200 字** 1 个 |
| 段段留钩 | 每段结尾必须有悬念/伏笔/反转预告 |
| 合规 | 无血腥/暴力/色情/恐怖/惊悚/低俗 |

### ①′ 原创路线（`一、高品质AI原创小说`，从零写时用）

| 参数 | 值 |
|---|---|
| 赛道 | 都市逆袭 / 玄幻修仙艳遇 / 古风爽文 / 惊悚恐怖 / 家庭情感（每题材给 3 个细分选题） |
| 反转节奏 | 每 **5 集**一个大反转，每 **1 集**一个小高潮，结尾留强悬念 |
| **单集出场人物** | **不超过 3 个** |
| **人物单段台词** | **不超过 15 字** |
| 环境禁令 | 禁止茅屋／破败房间／偏僻小屋；禁止粗布麻衣／破洞／补丁（不许用"惨"凸显弱势） |

> 这两条（单集 ≤3 人、台词 ≤15 字）**与分镜的台词时长预算直接相关**：15 字 ÷ 3.5~4.5 字/秒 ≈ 3.3~4.3 秒，
> 正好落在"镜头 1.5~5 秒"里。平台的台词时长预算（`director.FitDialogueDurations`）应以此为准。

### ⑤ 分镜（两份「五、」逐条对比）

| 参数 | 15 秒档（3D漫剧） | 10 秒档（最新豆包） |
|---|---|---|
| 片段时长范围 | **4–15 秒** | **4–10 秒** |
| 非最后片段优先 | 12 / 13 / 14 / 15 秒 | 8 / 9 / 10 秒 |
| 场景总时长不足时 | <12 秒 → 单片段 | <8 秒 → 单片段 |
| 台词超长拆分阈值 | >15 秒拆段 | >10 秒拆段 |
| 片段内小镜头时长 | 1.5–5 秒（极快可 1.2，极致可 6）；**平台取 1.5–4**（见下注） | **同** |
| 时间精度 | 支持小数（1.8 / 2.3 / 3.7 秒） | **同** |
| 镜内之和 | 必须**精确等于**片段时长 | **同** |
| 切割点 | 动作自然停顿处（站定/转身完成/视线定格/动作循环结束/对话间隙/关门后） | **同** |
| 无自然停顿 | 可插 0.5–1 秒"定格"镜头缓冲 | **同** |
| 运动切割 | "重叠"补偿：下片段开头重复上片段结尾最后 1–2 秒动作 | **同** |
| 旁白 | **一律禁止**独立旁白音色 → 优先转该角色内心独白，次选剧情内字幕/对白 | **同** |

**语速基准（两档一字不差，直接进常量）**：

| 情绪 | 字/秒 |
|---|---|
| 正常叙事／平静对话 | 3.5–4.5 |
| 轻松／日常／调侃 | 4–5 |
| 愤怒／激动／争吵 | 5–6.5 |
| 低沉／压抑／哽咽／犹豫 | 2.5–3.5 |
| 威严／宣告／战斗呐喊 | 3–4 |

**镜头级字段（每个小镜头必填，逐字段）**：

| 字段 | 要求 |
|---|---|
| `【镜头 X】起始秒-结束秒` | 小数秒 |
| `画面描述` | [景别]+[人物动作]+[表情]+[环境细节]+[光彩色调]+[特效（含完整技能名）]；CG 国漫质感词 |
| `音效` | 拟声词/环境音/动作音，分号隔开；无则写"无" |
| `台词` | `第X秒时 角色名说："…" 口型同步，语气：[…]，语速：[…]`；内心独白写 `内心独白-角色名`，**不写口型同步**且画面描述必须写"嘴巴闭合" |
| `字幕` | 仅剧情内文字（书信/石碑/面板），写位置+时间+"后期添加"；**对话台词字幕不在此生成** |
| `运镜` | [运动方式]+[角度词]（**角度必填**：平视/仰拍/俯拍/鸟瞰）；允许的运动方式 6 种：静止/慢慢向前推进/从左向右摇/跟随人物移动/慢动作/镜头晃动 |
| `镜头结束状态` | 精确描述最后一帧：人物位置、姿态、表情、视线方向、环境状态（**避免听觉/氛围词**如"寂静"） |

**片段级字段**：`片段编号`（同场景内递增，新场景重置）／`片段时长`／`场景名称`／`时间`／`内/外景`／`地点`／`人物`／`关键道具`／`负向提示词`（固定串）／`全局风格`（固定串）／新场景首片段加 `转场说明`（渐隐渐显+转场字幕"[地点・时间]"）／回忆加 `回忆标记`。

**连贯性三层**：
1. 同片段内：后一镜 `画面描述` 开头承接前一镜的 `镜头结束状态`
2. 同场景跨片段：下一片段首镜 `画面描述` 必须以"接上一片段结尾，"开头并复述结束状态
3. 跨场景：不需连贯，改渐隐渐显+转场字幕

**占位一致性（跨片段不可变项）**：关键道具的持有者/手握位置/朝向、角色相对站位（含距离）、特效落点形状颜色 —— 每条都要写进画面描述。

### ⑤′ 30 秒档（`【额外】测试版30S分镜指令`）——**它是三档里唯一带"叙事节奏约束"的**

片段 4–30 秒（非末片取 25–30；整场景 <20 秒 → 单片段 4–20）；台词 >30 秒拆段；
单镜 1.5–6 秒（情绪极致放宽 8 秒，极特殊可 1.2 秒）；**单镜台词 >8 秒 → 拆两镜**。

**它独有的六条节奏约束（10 秒档一条都没有）**：

| # | 约束 | 原话要点 |
|---|---|---|
| 1 | 首句台词锚点 | 有意义的首句台词必须在片段开始后 **12 秒内**出现，否则在第 8–12 秒插锚点台词 |
| 2 | 无台词段上限 | 连续无台词段落 **≤12 秒** |
| 3 | 核心情绪镜 | 核心情绪镜头 **≥5 秒** |
| 4 | **黄金比例** | 铺垫 **25–35%** / 核心台词与互动 **40–50%** / 情绪反应与余韵 **20–30%** |
| 5 | 镜头数自检 | 30 秒片段：1.5–2.5 秒/镜 → **12–20 镜**；2.5–5 秒 → **6–12 镜**；5–8 秒 → **4–6 镜**（少于 6 或多于 20 须复核） |
| 6 | 可行性预检 | 长跟随运镜起止点跨度 >**30 米** → 拆两镜头；长台词镜须在画面描述末尾加运镜填充句 |

> ⚠️ **这六条在平台上的落地情况（2026-09-29 审计 #6 的结论，别当成"已全部生效"）**
>
> **已落地 4 条**（实现写在 `internal/project/plan_contract.go` 的节奏门里，
> 口径来源 `internal/director/mode.go` 的 `Rhythm30`）：
> ① 首句台词 12 秒、② 无台词段上限、③ 核心情绪镜 ≥5 秒、以及"**前 30 秒必须给一次情绪释放**"。
>
> **未落地 2 条，而且是当前数据结构**判不了**的**：
>
> · **第 4 条黄金比例** —— 要判"这一镜属于铺垫/核心/余韵"哪一段，
>   镜头得先有**段位字段**。现在没有；**也不打算用 `HookType` 去猜**
>   （两者不是一回事：一个 `reveal` 完全可以落在铺垫段里）。
> · **第 6 条长跟随拆镜** —— 要判"这一镜里摄影机移动了多少米"，
>   而平台的结构里**没有距离量**（只在正文散文里可能出现）。
>   拿正则去捞"移动了多少米"是假判据，宁可空着。
>
> 第 5 条（镜头数自检）平台按 10 秒档的 `Plan*` 常量走，与 30 秒档的 12–20 镜口径不同档。
>
> **要真落地前两条，正解是加结构字段**（镜头的段位标记 / 运镜距离），
> 而不是在文本上凑判据 —— 这也是它们至今没做的原因。

**台词长的三档节奏**（30S 档给出，可直接当预算公式）：无台词或 <5 字 → 1.5–2.5 秒/镜；
短台词 5–15 字 → 约 2.5–4 秒/镜；长台词 >15 字 → **强制慢节奏**（15 字≈3.8 秒、20 字≈5 秒、30 字≈7.5 秒）。
**台词物理时长 = 字数 ÷ 语速；镜头时长 = MAX(台词物理时长, 动作时长)**；语气停顿约 0.5 秒、高潮留白 0.3–1 秒。

### 分镜的**正交结构**（这是全目录最容易被忽略的一点）

分镜不是一个环节、一份文档，而是 **「渲染风格 × 片段时长上限」的正交格子**，四份文件各占一格：

| | **3D CG 国漫** | **写实仿真人** |
|---|---|---|
| **10 秒上限** | `五、最新豆包十秒指令` | `【额外】仿真人10S分镜头指令` |
| **15 秒上限** | `五、3D漫剧15秒分镜指令` | `【额外】即梦仿真人15S分镜头指令` |
| **30 秒上限** | `【额外】测试版30S分镜指令`（测试档，只此一格） | — |

**风格轴改的不只是质感词**：
- 仿真人两版**删掉了 `【全局风格】` 与 `【转场说明】` 两个字段**（3D 两版都有）
- 仿真人的【负向提示词】多出「**塑料感，虚假光泽**」（3D 版止于「低质量」）
- 画面描述要求从「CG 国漫质感词（体积光/全局光照/边缘光/真实反射）」换成
  「写实仿真人质感（真实皮肤纹理/自然光效/柔和阴影/真实反射/景深感）」

**时长轴改的是数值**（四档平摊）：

| 项 | 3D·10s | 仿真人·10s | 3D·15s | 仿真人·15s | 30s 测试 |
|---|---|---|---|---|---|
| 片段区间（规则段） | 4–10 | 4–10 | 4–15 | 4–15 | 4–30 |
| 非末片段优先 | 8/9/10 | **7/8/9/10** | 12–15 | 12–15 | 25–30 |
| 整场景单片段阈值 | <8 秒 | **<10 秒** | <12 秒 | **<15 秒** | <20 秒 |
| 单镜时长 | 1.5–5（极致 6） | **1.5–4**（极致 5） | 1.5–5（极致 6） | 1.5–5（极致 6） | 1.5–6（极致 8） |
| 镜内台词延长阈值 | >5 秒 | **>4 秒** | >5 秒 | >5 秒 | **>8 秒→拆两镜** |
| 台词拆片段阈值 | >10 秒 | >10 秒 | >15 秒 | >15 秒 | >30 秒 |
| 常规节奏 | 2.5–4 秒/镜 | **2.0–3.5** | 2.5–4 | 2.5–4 | 2.5–5 |
| 慢节奏 | 4–6 秒/镜 | **3–5** | 4–6 | 4–6 | 5–8 |
| 语速五档 | ✅ | ✅ | ✅ | ✅ | ✅（**五份一字不差**） |

> **两个必须作者拍板的点**（子代理逐行核对时发现，我没自行改口径）：
>
> 1. **仿真人两份内部自相矛盾**：使用说明写「1-10 秒之间」/「1-15 秒之间」，
>    而 `【片段时长规则】` 段写「必须 4 秒～10 秒」/「4 秒～15 秒」。3D 两版是自洽的。
>    写代码常量必须选一个 —— 倾向以规则段的 4 秒下限为准（与 3D 档一致），但这属改口径。
> 2. **「整场景总时长不足 → 只出一个片段」的阈值四份各不相同**：
>    3D·10s `<8`、3D·15s `<12`（都是「上限 −2 秒」）；仿真人·10s `<10`、仿真人·15s `<15>`
>    （都等于上限本身）。看起来仿真人两版是**新口径**，但没写明谁覆盖谁。
>
> **另**：10 秒档（3D 或仿真人）都**没有** 30 秒档那六条叙事节奏约束（见上）。


### ④ 场景（`四、场景提示词指令`）

| 参数 | 值 |
|---|---|
| 画幅 | 横向 **16:9** 电影级大场景设定图 |
| 主视角 | 超广角/广角大场景建立镜头；**禁止**微距/特写/小景别/局部近景/小角落/平顶小空间 |
| 主图必含 | 天空／地平线／远山／巨大建筑群／开阔地貌 **至少两项** |
| 视角 | 每场景**只选一个主视角**（9 选 1），低角度仰视与窥视仰视不得作默认 |
| 配套物件 | **2–4 组**（前景 1–2、中景 1–2），禁逐件罗列 |
| 元素数（GPT 版） | 视觉元素 6–10 项（含 2–3 项配套物件）；适用剧情 2–4 项 |
| 命名 | 场景名**四字以上**带修饰词；隐性场景从环境主体派生名，**不得遗漏** |
| 四要素 | 环境类型、具体时间、空间氛围、视觉主要特征 |
| 无人 | 严禁人影、严禁角色人名（含衣物/身体部位/饰品等暗示人物存在的元素） |
