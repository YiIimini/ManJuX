# 实测：H3 ref2va 的参考图**对本机成片没有任何影响**（2026-09-27）

> **一句话**：`<Picture 1>` 目前是装饰。分镜里的人物长相与画面质感**只由文字提示词决定**，
> 定妆照/场景板改多少次都不会改变成片。这是"镜头里的人和定妆照不像 / 画风跟定妆照
> 不一致 / 改了定妆照也没用"这一组报障的**同一个根因**。

## 1. 三次对照实验（都能逐帧复现）

判据用的是**全片解码帧序列的 MD5**（`ffmpeg -f framemd5` 逐帧取哈希再串起来），
不是"看着差不多"。

  "电影级实拍质感"版本（原版是半风格化 3D 渲染），场景板同理；
- 提示词（已改成新版画风串）、种子、采样设置全部不动，只重渲 shot_011：

| 运行 | 参考图 | 全片帧指纹 |
|---|---|---|
| T2 | 旧（半风格化 3D 定妆照 + 旧场景板） | `1F711C0A76377AA85810D11FB841A5A4` |

（md5 不同），说明"参考图确实被读进去、被编码了"——只是对结果没有影响。

## 2. 已经排除的原因

| 嫌疑 | 结论 | 依据 |
|---|---|---|
| 条件缓存那条近路（编解码拆两个作业 + `.pt` 中转） | **排除** | 把 `render.cond_cache` 关掉（单图内联、就是官方接法）后产物仍逐帧一致（实验前后 `1F711C0A…` 不变），且实验三本身就是单图内联 |
| 社区底模（`Singularity …Pruned_v1.3_int8`） | **排除** | 换官方 `MiniMax_H3_ref2va_pruned_int8_convrot` 同样（实验三 C/D） |
| turbo 4 步蒸馏 LoRA 破坏 ref 路径 | **排除** | 不挂 LoRA 同样（实验三 E/F） |
| 平台侧的提示词装配 / 参考图上传 / 项目参数 | **排除** | 实验三是手搓图，与平台无关；上传文件已按 md5 核对到位 |
| 文本编码器没有视觉塔 | **排除** | `qwen3vl_32b_minimax_h3_nvfp4_awq` 里有 351 个 `visual.*` 张量；`comfy/text_encoders/minimax.py` 的 `tokenize_with_weights` 确实把参考图以 `<Picture N>` + vision 块塞进 token 流 |

## 3. 剩下的嫌疑（按可能性）

1. **本机四个 H3 底模全是"剪枝 + int8"转换版**（`Pruned_v1.3_int8` / `pruned_int8_convrot`）。
   参考分支（`conditioning["minimax_refs"]` 那条路）很可能在转换时被削掉或失效 ——
   盘上**没有任何未剪枝/未量化的 H3 ref2va 权重**可对照。
2. ComfyUI 版本（0.37.4）里的 H3 实现与这批权重的**组合**不匹配。
3. `ref_image_size=max` 与 int8 VAE 路径的交互（可能性较低：它只影响缩放口径）。

## 4. 最快判定法（2 分钟，不用重渲整集）

用实验三那张最小图：**换一套权重（或换 ComfyUI 版本）后，把两张截然不同的参考图各跑一次
22 帧**，比较全片帧指纹。

- 指纹**不同** → refs 通了，本机这批权重就是坏的：换掉它即可，之后"定妆照 → 成片"这条
  身份链才真正成立。
- 指纹**仍相同** → 问题在 ComfyUI 侧，要往上提 issue / 等版本更新。

复现要点（都已在本文记录）：`length=22`、`steps=8`、`noise_seed=424242`、
`ref_image_size=max`、`prompt="The person shown in <Picture 1> …"`、参考图
`abtest_shenyan.png` / `abtest_maicaipo.png`（在 `ComfyUI/input/`）。

## 5. 对"建模游戏感"的意义

**画风与质感**这件事的因果链本来是这样的：

```
定妆照（图像模型，25 步）→ 作为身份+风格参考 → H3 照着它渲每一镜
```

参考那一路既然不通，就只剩文字：而文字里写的是
`GUOFENG ANIMATED-FEATURE ART DIRECTION, a photoreal 3D surface with IDEALISED,
SEMI-STYLIZED faces…` —— 视频模型照字面读，就是"3D 动画角色/游戏渲染"。

所以顺序要反过来：

1. **先让 refs 能生效**（换权重验证，2 分钟判定）；
2. refs 一通，H3 就能吃到**实拍质感的定妆照**（图像侧已经验证：同一套改写措辞能把定妆照
   从"半风格化 3D"变成真实材质与肌肤质感的那一版）；
3. 在那之前，只改镜头侧措辞：实测**光影与材质会变**（对比/材质/反射更接近实拍），
   但脸仍然偏 CG —— 因为文字里还留着 `3D surface` / `SEMI-STYLIZED` 这些词。

另外顺带记一笔：调色档 `refer`/`refine`（不挂蒸馏 LoRA、24 步）与底模换代**都不是**
"建模感"的解药 —— 前者只是把每镜从 7 分钟拖到 15.5 分钟、细节略好一点；后者甚至更漂。
