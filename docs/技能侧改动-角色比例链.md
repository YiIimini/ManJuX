## 改动 ①（主改）：人类定妆卡里把「整身比例」移出去

**位置**：`scripts/manju_plan.py:545-550`（`HUMAN_PROPORTION_CLAUSE`）、`scripts/manju_plan.py:524-526`（`SHEET_TAIL['human']`）

### 现状：同一张卡，取景写半身、比例写全身

```python
# scripts/manju_plan.py:524-526  —— 定妆照收尾，取景=半身
SHEET_TAIL = {
    'human': 'plain pure white seamless background, upper-body framing, front-facing, '
             'no other people, no scenery, no props, no text, no letters, no watermark',
```

```python
# scripts/manju_plan.py:545-550  —— 比例锚点，最后一条是整身
HUMAN_PROPORTION_CLAUSE = (
    'Proportions must be balanced and idealised: the eye line sits at the vertical middle of the head; '
    ...
    'the shoulders are about two head-widths wide; the figure is seven and a half heads tall with a slim '
    'waist and long legs. Never distort these ratios, never lengthen the face and never enlarge the eyes.')
```

### 为什么必须改

半身画面里给全身比例，模型只能二选一。**实测（《求你们骂我》第 01 集，沈砚·一品）：出图就是全身立绘** ——
头偏大、肩约 1.5 个头宽、上身短、宽袍把手臂遮掉。

而这一集 64 个镜头里 **61 个是近景/中景/特写**（分布：近景 28 / 中景 20 / 特写 13 / 远景 3）：
一张全身立绘被要求「裁」出特写，头肩比与脸宽必然被重新诠释 —— 这就是「比例那么奇怪」的直接来源。

### 改成（可直接粘贴）

把一条常量拆成两条，**只把整身那一条移出定妆卡**：

```python
# 定妆卡用：半身幅里看得见、也量得到的那几条
HUMAN_FACE_PROPORTION_CLAUSE = (
    'Proportions must be balanced and idealised: the eye line sits at the vertical middle of the head; '
    'the eyes are one eye-width apart; the nose is about one third of the face length and the mouth about '
    'one fifth of it; the chin is about two thirds as wide as the cheekbones; the neck is slim and long; '
    'the shoulders are about two head-widths wide. '
    'Never distort these ratios, never lengthen the face and never enlarge the eyes.')

# 整身口径：全景/远景才用得上 —— 不进定妆卡。平台侧已按景别注入到需要它的镜头上（见"跨侧契约"）
HUMAN_FULLBODY_PROPORTION_CLAUSE = (
    'the figure is seven and a half heads tall with a slim waist and long legs.')
```

`ensure_sheet_tail`（`scripts/manju_plan.py:553-564`）只需换引用：

- 第 562 行的判据串 `'eye line sits at the vertical middle'` **保持不变**（它仍指向人脸锚点，仍然有效）；
- 第 563 行 `HUMAN_PROPORTION_CLAUSE` → `HUMAN_FACE_PROPORTION_CLAUSE`。

> 若倾向「保留整身句、把定妆取景改成全身」：**平台侧不建议**。本片 61/64 镜是中近特写，
> 全身参考图喂特写正是当前漂移的来源；反过来，定妆照半身 + 镜头按景别补整身，是目前验过的组合。

### 平台侧已做的兜底（所以这条不阻塞，已生产的包不必重出）

- **定妆链** `internal/pipeline/sheet_framing.go`：人类卡剥掉**整身项**（七头半的六种写法、
  `slim waist and long legs`、`full body` / `head-to-toe` / `whole body` 一类取景短语），
  脸部八条锚点**一条不动**。剥法是按 `,` `;` 句末 `.` 切小项、命中项**整项删**
  ——只删短语会留下 `the figure is tall with …` 这种平台自造的措辞。
- **镜头链** `internal/pipeline/shot_proportion.go`：按景别注入比例句的逐字子集 ——
  特写/近景只给脸五条；中景加颈与肩；全景/远景八条齐发；认不出景别的不注入。
  实测 56 个包 / 3137 镜 → **2413 镜注入（77%）**，改动前是 0。

## 改动 ②：`ensure_sheet_tail` 产出多余的点（`..`）

**位置**：`scripts/manju_plan.py:564`

真实卡上是 `…never enlarge the eyes.. plain pure white seamless background…`（双点）。

```python
return (body + '. ' if body else '') + tail + '.'
```

`body` 到这里已经以 `HUMAN_PROPORTION_CLAUSE` 自带的句点结尾，再追加 `. ` 就是双点。

```python
sep = '' if body.endswith('.') else '. '
return (body + sep if body else '') + tail + '.'
```

（第 563 行同型，但 `body` 由第 560 行 `'. '.join(...)` 生成、本身不带尾点，不会双点 —— 想统一防御也可以。）

## 改动 ③：`image_prompt` 里不要写**尺寸词**

真实卡实测：沈砚 `large bright lively eyes`、苏晚 `large glaring eyes`。
它们与比例锚点「两眼间距＝一个眼宽」「`never enlarge the eyes`」**直接冲突** ——
同一段提示词里两个相反的指令，模型只会折中。

两个方向都行（LLM 写作指令在你们手上，位置你们更清楚）：

- 在 `image_prompt` 的写作规范里加一句：眼睛只描述**形状与神态**
  （`almond-shaped eyes` / `calm level gaze` / `narrow hooded eyes`），**不许用尺寸词**
  （`large` / `big` / `huge` / `tiny` / `small`）；
- 或加进机检：人类卡 `image_prompt` 命中 `\b(large|big|huge|tiny|small)\b[^.]{0,20}\beyes?\b` 即报。
