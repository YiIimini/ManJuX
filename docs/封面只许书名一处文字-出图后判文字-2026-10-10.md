# 封面上只许有书名一处文字：口径收一处 + 出图后判文字（2026-10-10）

用户原话：「封面文字内容版本需要优化」。我按证据把它收成一句可机检的口径：
**封面上只许有书名一处文字**（用户在我给的四/五个候选项里选的正是这一条）。

## 一、先取证：那张封面到底哪里不对

平台自己的 VLM 读真机封面（`data/小说/离婚后，千亿前夫跪求复合/封面/封面.png`，16:16 生成）原话：

> 1) 有文字。在下三分之一、居中；主标题约占宽85%、高20%，**下方另有一行极小字**。
> 2) 主标题：《 离 婚 后 ， 千 亿 前 夫 跪 求 复 合 》；下方小字：**乱码/糊成一团**。
> 5) 有书名号《》和逗号；**下方乱码伪字/残笔**；无重复字、英文、水印、括号。
> 7) **不能**：主标题正确清晰，但底部乱码小字必须删掉或重做后才可用。

也就是说：**书名这一处是画对了的**，多出来的是**第二处文字**（一行乱码伪字）。而那份词里明明写着
`no other text, no subtitles, no watermark, no signature`。

### 为什么那句"不许有别的文字"没用

两条都是平台自己早就记下的口径：

1. **出图侧是 Qwen-Image，cfg=1.0 ⇒ 否定词不生效**（`pipeline/artstyle.go` 顶上那段）；
2. **提到的名词会被当成"要画的东西"** —— 2026-09-12「每个角色定妆照肩膀上都多了三个 Q 型小人」是同型事故
   （提示词里写了"别人/巴掌大的小人"，模型就照着画）。所以 `subtitle / watermark / caption / logo /
   signature` 这些词**一个都不该出现在图像提示词里**：既不生效，又等于点了一份菜单。

"只许有一处文字"只能用**正向陈述**表达。而书名的写法由官方 ON-SCREEN TEXT 决定 ——
「**没被英文引号括起来的文字，就是模型会画成字形的来源**」（`project/prompt_cjk.go` 顶上那段）。

## 二、修法（两条腿：口径收一处 + 出图后判一次）

### 1）画面文字口径收成**唯一出处** `coverTextClause`（`internal/server/novel_cover_prompt.go`）

```go
The only lettering anywhere in the image is the cover title "《书名》", one single block of large
elegant serif type in the lower third, centered and clearly legible, with every other part of the
frame staying pure photographic imagery.
```

三处都吃它，不再各写一遍：模板兜底词（`coverSeedPrompt`）、平台收口（`cleanCoverPrompt`）、
系统提示词举例（`coverPromptSys` 第 4 条改成"只许书名一处文字 + 用正向陈述 + 不许写否定句、不许点名那些名词"）。

### 2）LLM 的输出由平台**强制**收成那一句（`cleanCoverPrompt` → `enforceCoverText`）

逐句处理：

* 讲画面文字的整句（命中触发词 `title text/typeset/lettering/watermark/subtitle/...` 或否定式正则）**整句摘掉**；
* 其余句子里**抹掉书名那一处**（书名只由平台那一句承担 —— 一处文字，不是两处）；
* 末尾贴上 `coverTextClause`；**幂等**（再收一次结果不变）。

**这里有个坑（被老门咬出来的）**：第一版把"含书名的整句"一起摘掉 —— 真机那份词的第一句是
`Vertical 3:4 poster cover, single dominant subject ... for the Chinese short drama "《书名》", low-key
cinematic lighting, ultra-detailed.`，整句摘掉会把**构图与打光**一起丢掉（`TestCoverPromptEndpointForcesLLM`
当场红）。所以"提到书名"只抹书名那一处，不摘整句。

### 3）出图之后**看图判一次**（新 `internal/server/cover_text_qc.go`）

平台的规矩是"能确定性做到的不要让模型自觉"：提示词那侧改成正向口径以后，**模型照不照做还是要验**。

* `judgeCoverText` / `judgeCoverTextData`：让平台自己的视觉模型回严格 JSON
  （`texts` / `title_readable` / `other_than_title` / `note`）；
* 判定四态，**判不了就如实说**：没配视觉模型 / 读不出图 / 调用失败 / 返回解析不了 —— 都 `Judged=false`
  + `Err`，**绝不当成"干净"**；
* 不合格的定义：**书名之外还有字形**（`stray`）**或书名没认全**（封面就是靠标题认书）。

两条入口各自处置：

| 入口 | 有没有人盯着 | 处置 |
| --- | --- | --- |
| 自动出封面 `seedCoverFromTitle`（视频制作里"没有封面时先出一张"） | 没有 | 不合格 ⇒ **换种子重出一轮**（`coverTextTries=2`，有界）；仍不合格**如实播报**（warn），一样落盘但不假装干净；**只有最后那张落盘** |
| 出候选 `handleNovelCoverRedo`（弹窗 / 菜单一键） | 有人挑 | 每张候选各判各的（并发、3 分钟上限），把 `judged/stray/title_ok/text_note` 带进响应；候选卡上给三态标签：`文字 OK` / `文字不合规`（气泡里是模型原话）/ `文字未判`（说清"不等于验过"） |

## 三、真机实测

**探针**（`TestZZProbeCoverTextLive`，`MANJUX_LIVE_PROBE=1`，真调平台视觉模型，读真机 `settings.json`）：

```
判定：judged=true stray=true title_ok=true     耗时 2.05s
原话：书名之外还有别的字形：《离婚后，千亿前夫跪求复合》 / 底部一行小字：无法辨认；
      书名完整可读，但底部另有一行细小装饰性文字，非书名本身。
```

即：**新判定在真机上认得出这个缺陷**（和人工看的那张图一致），而且给了可直接播报的原话。

## 四、门与反向验证

**门** `internal/server/cover_text_clause_test.go`（7 条，判据都**直接喂闸门本体**）：

* `TestCoverTextClauseIsPositiveAndQuotesTitle` —— 口径本体：正向陈述 + 书名在英文引号里 + 引号外 0 汉字 +
  **一个否定词/那些名词都不许有**；
* `TestCoverSeedPromptHasExactlyOneTextClause` —— 模板词里书名**恰一处**，且画面文字逐字等于口径那一句；
* `TestCleanCoverPromptEnforcesOneTextClause` —— 收口后：画面描述留着、书名恰一处、结尾就是平台那一句、
  否定式残留为 0、Note 如实说摘了几处、**幂等**；
* `TestEnforceCoverTextKeepsSceneSentenceMentioningTitle` —— 反面针：只是"提到书名"的句子要留下；
* `TestJudgeCoverTextReportsVerdictAndNeverFakesClean` —— 假视觉模型：判出多余字样；没配 VLM ⇒
  **`Judged=false` + 说清原因**（不许假装干净）；
* `TestCoverTextRerollDecision` —— 重出策略穷举（第一轮不合格 ⇒ 重出；轮数用完 ⇒ 不重出 + 如实播报；
  合格 ⇒ 不啰嗦；没判成 ⇒ 不重出但要说清；书名没认全 ⇒ 同样不合格）；
* `TestCoverTextQCIsWiredIntoBothEntries` —— 两处接线 + 前端三态 + **落盘只在循环之后** +
  系统提示词不许退回 `no other text`。

**反向验证 9/9 全红**（`scratch/reverse_verify_cover_text.ps1`）：口径改否定式 / 默认词不用口径 /
收口不强制 / 没配 VLM 假装干净 / 重出无边界 / 自动路径不判文字 / 候选卡不显示"未判" / 系统提示词退回老路 /
重出期间也落盘 —— 九条各自都让对应的门变红。

**被自己的门咬出 1 处**：口径原来由**两句**组成（`... in the lower third. Everything else ... imagery.`），
而收口是**按句**摘掉再贴这一句的 ⇒ 第二句被当成"画面描述"留下 ⇒ **越收越长**（幂等断言当场红）。
改法：口径自身必须是**一句话**（句内不含句号）。

## 五、边界与如实说明（没做到的就说没做到）

* **存量那张封面不会自动变干净**：要看新的干净封面，得重新出一张（菜单「按书名出封面」或封面重做弹窗）。
* **技能端留档词（第一档）原样使用、平台不改写它**：如果留档词里写着 `no other text`，出图仍可能多画一行字 ——
  但现在**会被判出来**（候选卡/自动路径播报）；要彻底修就点「AI 按书名写词」再勾「存回留档」。
* **没有跑"重出一定更干净"的 A/B**：本轮只证明了①新判定认得出缺陷、②重出策略有界且如实播报；
  ComfyUI 这边的出图 A/B（同一 prompt 重出几轮里干净的比例）**没量**。
* 判定用平台自己的视觉模型 ⇒ 它的结论是**模型判断**，不是像素级 OCR；代价是每张候选一次视觉调用
  （自动出封面那条最多 2 次）。
* 「书名以外的文字」这条口径不管**错别字/错排**之外的美学问题（字体好不好看不在本题内）。
