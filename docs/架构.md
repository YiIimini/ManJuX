# ManJuX 架构

> 技术底座:Go 1.25 + Wails v2(桌面)+ Vue 3 + Vite + Element Plus + Tailwind(界面)+ ffmpeg(合成/质检)。
> 设计目标:模块化、解耦、可扩展 —— 新增渲染引擎或管线阶段不动已有代码。

## 总体结构

```
┌────────────────────────────────────────────────┐
│ Wails 原生窗口(桌面 exe,单实例)                 │
│  ┌──────────────────────────────────────────┐  │
│  │ Vue 3 前端(embed 嵌入 exe)               │  │
│  │  Home / ProjectView / Settings + 抽屉组件  │  │
│  └───────────────┬──────────────────────────┘  │
│                  │ fetch /api/* + SSE /api/events│
│  ┌───────────────▼──────────────────────────┐  │
│  │ internal/server  REST API + SSE 事件出口    │  │
│  └───────────────┬──────────────────────────┘  │
│  ┌───────────────▼──────────────────────────┐  │
│  │ internal/pipeline 五阶段编排器(协调器)     │  │
│  │  script → assets → render → qc → assemble │  │
│  └──┬──────────┬──────────┬─────────┬────────┘  │
│  director  engine(注册表) compose  qc          │
│  (LLM直出) ├─ comfyengine(本地 ComfyUI)        │
│           └─ h3api(MiniMax 云端 API)           │
│  project(域模型/存储) config(设置) ff(封装)     │
└────────────────────────────────────────────────┘
        同进程另起独立 HTTP(127.0.0.1:8790,浏览器入口/排障)
```

## 模块职责

| 包 | 职责 | 关键点 |
|---|---|---|
| `main.go` | Wails 装配 | 窗口/单实例锁(Wails 内建)/日志 Tee/独立 HTTP |
| `internal/server` | HTTP 层 | REST + SSE;`APIHandler()` 给 Wails 直通;文件服务防路径穿越;API Key 回显脱敏 |
| `internal/pipeline` | 编排器 | 每项目单运行实例;阶段可单跑(`phase`+`only`);事件总线(SSE 推送+环形历史回放);断点续跑(输入指纹) |
| `internal/project` | 域模型 | 项目/方案/资产/清单结构体;`StageParams` 阶段参数(项目级快照+Sanitize 钳制);原子写 |
| `internal/director` | LLM 直出 | H3 官方提示词规范全量内嵌的系统提示(六段式/三段式/S1-S2/`<d>` 台词/亮度护栏);JSON 容错解析+二次修复 |
| `internal/engine` | 引擎抽象 | `Engine` 接口(Name/Available/Render)+ 注册表;`AlignLength` 17k+5 帧网格;`SnapCanvas` 32 对齐 |
| `internal/engine/comfyengine` | 本地引擎 | 工作流程序化组装(R2V/I2V→BasicGuider 采样链);两阶段条件缓存(.pt+sidecar 记账);ComfyUI 代管启动;产物 animated 文件回收 |
| `internal/engine/h3api` | 云端引擎 | `/v2/video_generation` 异步任务(10s 轮询/20min 上限);参考图 base64 data URI;取消防空跑计费 |
| `internal/compose` | 合成 | 逐镜规范化重编码(禁流复制保 P 帧链)→ cut/xfade(acrossfade)拼接 → ASS 字幕 + loudnorm + faststart;SRT 同步导出 |
| `internal/qc` | 质检 | ffprobe 时长/音轨/分辨率 + ffmpeg 抽 3 帧灰度统计(暗像素阈值黑屏防线) |
| `internal/ff` | ffmpeg 封装 | PATH/显式路径解析;Run(30min 上限+stderr 摘要);Probe |
| `internal/config` | 设置 | data/settings.json 原子读写;默认值自适应 exe 目录 |
| `internal/tray` / `browser` | 可选 | 系统托盘 / Edge App 独立窗口(独立 HTTP 模式用) |
| `internal/watchdog` | 单实例 | 命名互斥量(独立 HTTP 模式备用;桌面模式用 Wails 内建锁) |

## 双引擎设计

```go
type Engine interface {
    Name() string
    Available(ctx) error      // 探测 + 修复指引
    Render(ctx, Job) (*Result, error)
}
```

- **auto 模式**:先探本地 ComfyUI(存活或可代管启动)→ 不可用切云端 API;两边都不可用报可读错误。
- **每镜可重渲**(`only` 参数),manifest 记录输入指纹(提示词+资产指纹+参数+seed),同指纹产物跳过(断点续跑),资产变更自动视为过期。

## 关键工程纪律(源自 H3 生产实践)

1. 帧数 17k+5 网格(Go 负数取模已归一);宽高 32 整除、短边 ≤768。
2. UNET/LoRA 文件名大小写敏感,配置须与 ComfyUI 实际文件一致。
3. trim/拼接必须重编码(H3 源仅首帧 IDR);成片必须 +faststart。
4. 音频 VAE 缺失 = 黑屏;H3 产物自带 32kHz 立体声,不另做 TTS。
5. 缓存名带 项目_镜头_指纹 前缀,防跨项目串用。

## 数据流(渲染一镜)

```
Job{prompt, refs, w×h, length, seed, steps}
 → engine 选择(auto/comfy/api)
 → [comfy] 参考图上传 → encode(CondSave 缓存命中则跳过) → 采样图提交 /prompt
          → 轮询 /history(progress 事件) → animated 产物下载到 clips/
 → [api]   content[] 组装(text+reference_image) → 创建任务 → 10s 轮询 → 下载
 → manifest 落盘(状态/指纹/引擎) → SSE 镜头完成事件 → 前端卡片点亮
```
