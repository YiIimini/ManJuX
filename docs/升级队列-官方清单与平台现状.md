## E. 开源参考实现：最该抄的 5 条（含出处）

1. **H3 单镜生成方言**（`drama-skills` MIT，`skills/short-drama-video-prompts/references/minimax-h3.md`）
   —— 已落：语速 4.1 字/秒 ✅、参考图上限 9 张 ✅（本轮补）。剩余：素材总量上限（3 视频/3 音频 ➖ 不用）。
2. **规则编号 + 档位 + 脚本门 + 审查闭环**（`drama-skills` `stage-contract.md` SHT-01..29 / CON-01..07；四档
   structural_invariant/reviewed_invariant/craft_default/taste_option）—— **待做**：给平台的散装门编上号与档位。
3. **节拍认领 + 时长算术**（`shuohao-skills` Apache-2.0）—— "每拍几秒是**算出来的**，不要让模型估" +
   台词秒数 ≤ 镜头秒数 + 每集总时长 ±15%。
   **2026-09-28 已落**：镜头时长 = max(台词需要秒数, **刀数 × 1.5 秒**, 下限 4) 封顶 10（只加不减）；
   切镜抬起来的会在明细里写明"切镜需要(N 刀 × 1.5 秒)"；每集总时长偏离目标 >15% 时如实报差额。
4. **参考图三态 + 连续性锁**（`drama-skills` `character-consistency-across-shots.md`）—— 平台的 assets 已有
   `missing` 上报；**待做**：把"哪些图能进参考槽"变成显式状态（防止静默降级成文生图）。
5. **锚点派生 + 人脸嵌入质检**（`shuohao-skills` + `YYC3` 的 insightface 512 维/阈值 0.85/pre_anchor）
   —— 本机可跑、成本近零的**确定性**"不换脸"硬门。**待做**：需要一个人脸嵌入模型（下载：按规矩先问用户）。
