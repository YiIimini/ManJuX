## I. 平台侧待办：读技能侧的设定集（**证据驱动，别再让模型凭空发明**）

**背景（2026-09-28 读盘实测）**：技能侧 `data/小说/<作品>/设定集/` 里**已经有**平台正需要的数据，
而且是结构化的：`重点道具表.md`（名称／外形／功能边界／来历／标志性细节／首次出现／锚定章／参与情节）、
`人物外形锚表.md`（含比例锚点）、`数字锚表.md`。**而平台从来不读它们**（全仓搜索无引用）——
只把 `正文/**` 喂给分镜 LLM。

⇒ 由此产生的三类毛病，根因都在平台侧，不在技能侧：
1. 分镜里 **16 处器物动作却没写 `prop_ids`**（器物漂移的高发区）
2. **4 张人形角色卡缺比例锚点** ⇒ 同集内头身比互相打架
3. 器物/人物的 id 与命名靠模型现编，跨集不稳定

**要做的事**：
- 在装配/生成入口读 `设定集/重点道具表.md` → 生成 `plan.props` 卡片（含英文 image_prompt），
  并按表里的"锚定章"把道具**确定性**列进对应集次镜头的 `prop_ids`
- 读 `人物外形锚表.md` → 把比例锚点写进角色卡 `image_prompt`（缺就补，有就以表为准）
- 与技能侧对齐两条**机器可读键**（已写进 `docs/平台侧交付-技能侧整改单-2026-09-28.md` §3 的 S1/S2）：
  道具表的 `锚定章_机器: 1,5,14`、锚表的 `比例锚_机器: 8.5 头身`
- 表缺失时**退回现状**（LLM 自产）并如实播报，不能因为读不到表就报错停工

**判据**：真方案再跑一遍预检，`plan.props` 那两条告警（缺 prop_ids / 缺比例锚点）归零。
