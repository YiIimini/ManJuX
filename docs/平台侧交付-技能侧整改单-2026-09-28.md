## 2. 请**冻结**的约定（C1–C5：平台解析依赖它们，改了就断）

> 这五条**不是**要求你们额外做什么，而是**请保持现状**、并在规范里写明"平台依赖此约定"。
> 平台侧对应实现：`internal/pipeline`（读 `data/小说/**`）＋ `cmd/preflight`。

| 编号 | 约定 | 平台为什么依赖它 |
|---|---|---|
| **C1** | 正文文件 **UTF-8 无 BOM ＋ LF** | 平台按 UTF-8 直读纯文本；加 BOM 会在首行引入不可见字符，标题正则与首行判据都会跟着失配 |
| **C2** | 路径与命名 `<作品>/正文/<卷目录>/第NNN章_章名.md` | 平台按"章号 = 集号"定位成片与产物；文件名是**唯一**的集号来源 |
| **C3** | **一章 = 一集**，1:1 不破 | 平台集号直接取章号。**一章塞两集内容**或**一集拆两章**都会让成片与集号错位（这是分集错误里最难查的一类） |
| **C4** | 章名可直接上片头卡 | 平台把章名当**集名**（片头卡与产物命名都用它）。请避免 `·`、`/`、`:`、`"` 等会破坏路径或不适合上屏的字符 |
| **C5** | 正文里**不出现**技术指令 | 平台把正文整段喂给分镜 LLM。正文里一旦混入"镜头/景别/提示词"这类词，模型会把它们当**剧情**去写进分镜 |

## 3. 建议（S1–S2，非必修）

> 两条都遵循你们自己 `项目产出结构与命名契约.md` §2.3 立下的先例
> （"**别再只写 prose**"：给机器读的字段就用字段）。改动量都是**一行**。

### S1 重点道具表：加一行机器可读的锚定章

- **现状**：`设定集/重点道具表.md` 每个道具一张 `| 项 | 内容 |` 表，其中
  `| 锚定章 | 第 1 章（新锚：第 5 章"只能改既有的字"、第 14 章"一笔换一笔"）|` —— **是 prose**，
  平台要么解析不了，要么只能正则碰运气。
- **建议**：在同一张表里**加一行**（不动原有那行）：

  ```
  | 锚定章_机器 | 1,5,14 |
  ```

  写正文的章号（阿拉伯数字、逗号分隔、升序）。原有的 prose 行**保留**——它是给人读的。
- **平台拿它做什么**：把那几章的分镜**自动列进该道具的 `prop_ids`**（器物锚定的**确定性**来源），
  而不是像现在这样指望模型每镜自觉带上。

### S2 人物外形锚表：比例锚点写成可解析值

- **现状**：比例锚点在表里是散文式描述（`6.5 KB` 的表里混着"八点五头身"这类中文写法）。
- **建议**：加一行机器可读值：

  ```
  | 比例锚_机器 | 8.5 头身 |
  ```

  （数值用阿拉伯数字；单位就写 `头身`。）平台侧的实测：**4 张人形角色卡缺比例锚点** ⇒ 同一集里
  两个角色的头身比会互相打架。有这一行就能**确定性**写进角色卡，不再靠模型记得。
- 若某角色刻意不按统一比例（如 Q 版、异形），该行写 `n/a` 并在旁边注明理由即可。

## 5. 复核命令（你们那边可自跑，不必等平台侧）

```powershell
# ① 编码与命名（期望：88/88 都是 无BOM + LF，文件名形如 第NNN章_章名.md）
Get-ChildItem "D:\Ai\Datas\ManJuX\data\小说\<作品>\正文" -Recurse -File -Filter *.md | ForEach-Object {
  $b = [IO.File]::ReadAllBytes($_.FullName)
  $bom = if ($b.Length -ge 3 -and $b[0] -eq 0xEF -and $b[1] -eq 0xBB -and $b[2] -eq 0xBF) { '有BOM' } else { '无BOM' }
  $eol = if ([Text.Encoding]::UTF8.GetString($b) -match "`r`n") { 'CRLF' } else { 'LF' }
  "{0}`t{1} {2}" -f $_.Name, $bom, $eol
}

# ② 正文不含技术指令（期望：全部 0 处）
foreach ($kw in '镜头','景别','提示词','分镜','画面提示','机位','prompt','T2I','参考图') {
  $n = (Get-ChildItem "D:\Ai\Datas\ManJuX\data\小说\<作品>\正文" -Recurse -File -Filter *.md |
        Select-String -Pattern $kw).Count
  "{0}`t{1}" -f $kw, $n
}
```
