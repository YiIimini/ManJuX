## 1. 本会话的决策与落地

### 1.1 画风：2D 漫画 → **国风电影级**（用户规则：一切创作产物的电影级画面风格必须国风）

三层根因叠加：
1. 平台默认画风预设硬编码成 `guoman_2d`（国漫二维动画）→ 已换成新增的 `guofeng_cinematic`；
2. LLM 直出提示词明文要求"必须是动画风格（donghua/anime/cel-shaded），绝不写实"→ 已改成国风电影级 + 半风格化脸；
3. 介质块本身写死 `2D/2.5D animation, hand-drawn line art, flat cel-shaded` → 已迁到"photoreal 3D 表面 + 理想化半风格化脸"，渲染侧 NEGATIVE 里**显式排除平涂卡通**。

顺带修掉：风格串里含 `3d` 就被读成"要 3D CG 手办"（会写出 `BJD-inspired sculpted forms`）→ 判据收窄到 `bjd / 虚拟人 / 3d render / 3d cg`。

**保留能力**：要二维动画的项目把预设换回 `guoman_2d`；要真人实拍走 `live_action` 并关 `script.stylized_faces`。

### 1.2 角色比例

- 定妆照链：剥掉**整身口径**（七头半 / 腰腿 / full body / head-to-toe），按项整删不留残迹；脸部八条锚点一条不动；
- 镜头链：按景别注入技能侧比例句的**逐字子集**（特写/近景给脸五条、中景加颈肩、全景/远景八条齐发），实测 3137 镜 → 2413 镜注入（77%，改动前 0）。

### 1.3 定妆照取景（含一次我自己的回归，已修）

- **头顶被裁**：卡里写死 `upper-body framing`（半身）+ 出图 768×1344 竖幅 → 装不下整个头。修法：取景**按画幅算**（竖幅→胸像+头顶留白；横幅→头肩），并剥掉卡里那句；
- **回归**：剥 `front-facing` 时替代措辞太弱 → 出了四分之三侧脸。已把 `front-facing` 放回来并写强（`shot STRAIGHT-ON from the front … both eyes visible at the same size and symmetric, nose and chin pointing at the camera`）；
- 直出模板不再让 LLM 写取景/机位/视线方向（取景由渲染器按 kind + 画幅给）。

### 1.4 ComfyUI 生命周期（用户批评成立）

- 原行为：空闲 10 分钟**杀掉进程**（`comfyengine/idle.go`）。已改为空闲只 `/free` **卸模型释放显存**，**进程常驻**；
- 关进程只剩两个时机：**退出平台**（`main.go` 的 OnShutdown → StopAdmin）与**管理页手动「停止引擎」**；
- 顺带修：应用重启后看门狗从不认领 pidfile → 空闲治理整条静默失效。

### 1.5 人物外形锚表（新机制）

- 实证：小说第 001 章对主角的外貌描写**为零**，而 LLM 写出的角色卡有一整套外形 → **整套是 LLM 现编的**（不可复现、作者无落点）；
- 平台侧：新增 `readCharacterSheet`，读 `<书名>/设定集/*人物外形*.md`，作为**硬约束**拼在正文前（带抬头"逐项照抄"）+ 事件流日志；直出规则要求 LLM 逐项照抄；

### 1.6 技能侧停脚本 + 入口隐藏

- **闸门**：`scripts/check.ps1` 六门全过才能提交（gofmt / go vet / go build / go test 14 包 / vite build / third_party 补丁）；

- **不弹黑窗口**：任何脚本/子进程一律隐藏窗口启动；
- **产物归属**：一切创作产物输出到 `data\小说\<书名>\`；平台运行目录 `data\projects\**` 归平台；
