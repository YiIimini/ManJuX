## 1. 规定（照抄，别再各写一套）

| 项 | 规定 |
|---|---|
| **允许** | 汉字 ／ **全角**标点（`，。！？；、：·—…《》〈〉「」『』【】（）〔〕`）／ 阿拉伯数字 ／ 拉丁字母 |
| **禁止** | **一切 ASCII 标点与空格**（`, . ; : ! ? ' " ( ) [ ] { } \\ / \| < > * - _ ~ @ # $ % ^ & + =` 与 `0x20` 空格）／ 控制字符与不可见字符（BOM、零宽、制表符）／ 首尾空白 ／ 结尾句点 |
| **长度** | **章名 ≤ 14 字**（平台把它当集名上片头卡，一屏一行要读得完）／**书名 ≤ 20 字** |
| **唯一性** | 章名**全书唯一**；重名用 `（二）` 后缀（全角括号） |
| **保留名** | 不得等于 `CON/PRN/AUX/NUL/COM1-9/LPT1-9`（章名即文件名） |

**为什么统一到"全角"而不是"只禁几个"**：三处会被打穿，逐条有据 ——

| 类别 | 会被什么打穿 | 依据 |
|---|---|---|
| **文件系统** | `\\ / : * ? " < > \|`；**半角冒号** | Windows 非法文件名；**半角冒号触发 NTFS ADS 陷阱**（技能侧既有口径，实测踩过）。**章名即文件名**，这也是你们 C2 的同一个约束 |
| **字幕格式** | `{ }` 与 `\\` | **ASS**：`{}` 是**覆写标签块**，且**块内无法识别的内容会被静默忽略** ⇒ 章名上屏会**吞字**。依据：Subtitle Edit《ASSA Override Tags Reference》<https://subtitleedit.github.io/subtitleedit/reference/assa-override-tags.html>（"Override tags are enclosed in curly braces `{}`" / "Any unrecognized text within override blocks is silently ignored"）。你们产物里就有 `output/final-<集>.ass`，片头卡同理 |
| **导出与上屏** | 其余 ASCII 标点与空格 | 半角逗号/分号/引号/括号会撞**分镜与 CSV/JSON 导出的分隔符**（**这一条是我方判断**，依据导出格式，不是外部标准）；半角与全角混排上屏不齐 |

> 诚实标注：① Windows 字符集与 ADS、② ASS `{}` 语义 —— 有外部/既有依据；③"半角标点族一律禁"是**我方为统一而定的口径**（宁可规则简单可机检，也不留"这个半角可以那个不行"的灰区）。

## 4. 一点边界（免得来回对齐）

- **本规定只管"章名/书名字符串本身"**，不管正文内的标点（正文用弯引号 `“ ”`，那是另一条口径，见 `--check-quote`）。
- **顿号/逗号一律全角**：书名里的停顿写 `，` 或 `、`，不写 `,`；本书书名《补碑人改命，守钟女逆时》即为示范。
- **旧作品不追溯改名**：本规定**从新作品起生效**；对已交付作品只在你们**明确要求**时才改名（改名会牵动文件名＝集号，属平台侧动作，我们配合）。
