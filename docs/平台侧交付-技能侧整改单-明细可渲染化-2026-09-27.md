## 1. R1（P0）每镜补 `h3_prompt` —— 唯一的硬阻塞

**平台渲染吃的是 `h3_prompt`**（`project.Shot.H3Prompt`），它直接进 H3。而现在的字段是：

```text
episode, id, duration, shot_size, scene, characters, mode, view, view_note, angle_zh,
view_official_vocab, camera, hook_type, end_state, action, action_en, emotion, sound,
dialogue, narration, scene_landmarks, light          ← 21 个字段，没有 h3_prompt
```

对照：旧包 `plan/plan.json` 的镜头字段里有 `h3_prompt` + `keyframe_prompt`（所以平台现在只能靠它渲染）。
**而你们其实已经生成了这些提示词** —— `分镜/H3-提示词.md` 里就是 **2462 个 `text` 块**（每镜一段六段式）。
缺的只是"把它绑回每一镜"。

**要的形态**：`shots[].h3_prompt` = 该镜在 `H3-提示词.md` 里那一块的**逐字内容**（不含围栏、不含 `#### 第NN集 · S01 / 5s` 标题行）。

**口径不变**（你们已经在守，重复一遍免得回退）：六段式顺序、`retention_analysis` 不写 `(Sx)`、
风格句写在 `[Shot 1]` 之前（ref2va）、台词写在 `<d>[Chinese]…</d>` 内、单词数往官方 350–500 靠。

## 2. R2（P0）引用要 ID 化（平台按 ID 绑参考图）

平台现在导入的形态（实测自 `漫剧脚本/求你们骂我·第01集·求你们骂我/plan/plan.json`）：

```jsonc
// 卡（顶层）
"characters": [{ "id": "char_01", "name": "沈砚·一品", "kind": "human", "voice": "…", "image_prompt": "…", "description": "…" }],
"scenes":     [{ "id": "scene_01", "name": "临水城",   "image_prompt": "…", "landmarks": "…", "light_state": "…" }],
"props":      [{ "id": "prop_01",  "name": "一本簿子 ＋ 半截炭条", "en": "…" }],

// 镜头引用的是**卡 ID**
"shots": [{ "id": 1, "scene": "scene_01", "characters": ["char_01"] }]
```

而新明细现在是：`"scene": "临水城"`（中文名）、`"characters": ["Shen Yan"]`（英文人名）。
名字是给人看的，**ID 是给机器绑参考图的** —— 只靠名字会遇到同名/造型档（`沈砚` vs `沈砚·一品`）歧义。

**要的形态（二选一，都行）**：
- **甲（推荐，改动最小）**：`shots[]` 里**另加** `scene_id` 与 `character_ids`（保留现有的 `scene` / `characters` 供人读）；
- **乙**：直接把 `scene` / `characters` 改写成 ID（那就要保证卡里有同名 ID 可对）。

> 造型档请**各自给独立 ID**（`char_01` = 沈砚·一品 这样），平台按 ID 取参考图、按 `name` 显示。

## 3. R3（P0）把卡也放进同一个 JSON

平台建项目要用三类卡（角色/场景/道具），字段就是下面这些（**平台契约字段名，逐字**）：

| 卡 | 字段 |
|---|---|
| `characters[]` | `id` / `name` / `kind`（`human`/`object`/`spirit_pet`/`beast`/`incorporeal`/`chibi`）/ `description` / **`image_prompt`**（定妆照英文提示词 = 你们卡片里的「① 定妆」串）/ `voice`（英文声线描述） |
| `scenes[]` | `id` / `name` / `description` / **`image_prompt`**（环境建立图提示词）/ `landmarks` / `light_state` |
| `props[]` | `id` / `name` / `en`（英文外观短语）/ `description` / `image_prompt` |

**为什么值得你们做**：这些内容你们**都已经有了** —— `素材/{角色卡,场景卡,道具卡}.md` 里就是成品，
`素材/_llm/*.json` 是它的配料缓存。平台现在为了拿到"角色定妆串"已经在**解析你们的 markdown**
（`internal/project/char_cards.go`，N4 那条），场景卡与道具卡再各写一个解析器就是三处 ——
**格式一改就三处一起坏**（我们刚踩过：你们角色卡是 **CRLF**，我们第一版正则少了 `\r?`，
真机上解析出 **0 个角色**，而夹具用 LF 所以测试还是绿的）。所以**卡也进 JSON** 才是长久解。

> 若你们坚持卡只留 markdown：平台可以继续解析（角色那条已能用），但请**冻结 markdown 的结构**
> 并在改动时通知 —— 那就等于把"格式契约"写在 markdown 里，不如直接进 JSON。

## 6. 验收（你们能自己跑；平台侧也会跑同一套）

**契约硬指标**（平台 `project.ValidatePlan` 会逐条判，fails 拒收 / warns 提示）：

| 判据 | 要求 |
|---|---|
| `h3_prompt` | 每镜非空 |
| 时长 | 单镜 **4–10 秒**（整数） |
| `hook_type` | ∈ 官方 **10** 个：`setup`/`visual-joke`/`reversal`/`reveal`/`callback`/`suspense`/`tender`/`chase`/`expression-beat`/`climax` |
| `view` | 空 **或** ∈ 官方 9 条；**建立镜头与远景/全景必须非空**（这是平台 09-27 裁定 A 的口径，你们已知） |
| 特写/近景 | `characters` 非空（脸上特写没卡 = 每次换一张脸） |
| 引用完整性 | `scene_id` ∈ `scenes[].id`、`character_ids` ⊆ `characters[].id` |
| 台词说话人 | 必须匹配某个 `characters[].name`，或画外音标签（`旁白`/`系统`/`画外音`/`内心`） |

**自证脚本**（把 `<项目>` 换成书目录即可；你们生成器就是 Python）：

```python
import json, sys, collections
p = r"<项目>\分镜\分镜明细.json"
d = json.load(open(p, encoding="utf-8"))
shots, chars, scenes = d["shots"], d.get("characters", []), d.get("scenes", [])
# 官方 9 条（文件里每镜内嵌了 view_official_vocab，优先用它；没有就用这份逐字常量）
OFFICIAL_9 = {
    "ultra-wide 45-degree aerial view", "ultra-wide aerial view", "low-altitude flying aerial view",
    "ultra-wide eye-level deep perspective", "compressed distant depth", "low-angle upward view",
    "low-angle peeking upward view", "low-angle strong perspective", "telephoto compression",
}
VOCAB = set((shots[0].get("view_official_vocab") if shots else None) or OFFICIAL_9) or OFFICIAL_9
HOOK = {"setup","visual-joke","reversal","reveal","callback","suspense","tender","chase","expression-beat","climax"}
cid, sid = {c["id"] for c in chars}, {s["id"] for s in scenes}
bad = collections.Counter()
for s in shots:
    if not (s.get("h3_prompt") or "").strip(): bad["缺 h3_prompt"] += 1
    if not (4 <= int(s["duration"]) <= 10):    bad["时长越界"] += 1
    if s.get("hook_type") not in HOOK:         bad["hook_type 越界"] += 1
    v = (s.get("view") or "").strip()
    if v and v not in VOCAB:                   bad["view 越界"] += 1
    if s.get("scene_id") and s["scene_id"] not in sid: bad["scene_id 悬空"] += 1
    for c in (s.get("character_ids") or []):
        if c not in cid: bad["character_ids 悬空"] += 1
    if ("特写" in s["shot_size"] or "近景" in s["shot_size"]) and not (s.get("character_ids") or s.get("characters")):
        bad["特写/近景无角色"] += 1
print("镜头", len(shots), "角色", len(chars), "场景", len(scenes))
print("问题：" + ("无" if not bad else ", ".join(f"{k}×{v}" for k, v in bad.items())))
```

期望输出：**问题：无**。
